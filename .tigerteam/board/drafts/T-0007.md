## Goal
Add Grok (xAI) alongside Claude and ChatGPT. The PM located the endpoint by
hand — it is not guessable, so take these facts as given and do not go looking
for alternatives:

```
GET https://cli-chat-proxy.grok.com/v1/billing?format=credits
Authorization: Bearer <token>
x-grok-client-mode: grok-build
Accept: application/json
```

Verified: **HTTP 200**. The real response is committed as
`QuotaKit/Tests/QuotaKitTests/Fixtures/grok-billing-credits.json`.

## Context
- **Credentials**: `~/.grok/auth.json`. Its top level is keyed by OIDC scope —
  a single key of the form `https://auth.x.ai::<client-id>` whose value holds
  `key` (the bearer JWT, ~6 h lifetime), `refresh_token`, `expires_at`, `email`
  and other profile fields.
  **Address it by explicit path**, exactly as `Claude.credentials(from:)` does:
  take the first top-level key with the prefix `https://auth.x.ai::`, then read
  its `key` field. Do **not** use `JSONValue.firstValue(forKey:)` — AGENTS.md
  gotcha 4; this file holds several credential-shaped fields and a
  breadth-first search can return the wrong one.
- Response shape (see fixture): `config.creditUsagePercent` (63.0),
  `config.currentPeriod.{type,start,end}` with type
  `USAGE_PERIOD_TYPE_WEEKLY`, `config.productUsage[]` of
  `{product, usagePercent}`, and `config.onDemandCap`, `config.onDemandUsed`,
  `config.prepaidBalance`, each an object `{val: Number}`.
- Follow `ClaudeSources.swift` for structure: a `Grok` enum with the shared
  parsing plus a `GrokLiveSource: QuotaSource`. There is no local source.
- `HybridProvider` accepts `local: nil`.

## Design — implement exactly this
```swift
public enum Grok {
    public static let providerID = "grok"
    public static let displayName = "Grok"

    /// Reads the bearer token out of `~/.grok/auth.json`, addressing the OIDC
    /// scope subtree explicitly rather than searching the document.
    static func credentials(from json: JSONValue) throws -> String

    /// Builds the snapshot from a `/v1/billing?format=credits` body.
    static func snapshot(from root: JSONValue, observedAt: Date) -> ProviderSnapshot?
}

public struct GrokLiveSource: QuotaSource {
    public init(
        authFile: URL = /* ~/.grok/auth.json */,
        endpoint: URL = /* the URL above */,
        session: URLSession = .shared
    )
}
```

Mapping — **one** window, not four:
- id `credits`, label `"Week"`, kind `.weekly`, `usedPercent` =
  `config.creditUsagePercent`, `resetsAt` = `config.currentPeriod.end`,
  `windowMinutes` = 10080 when `currentPeriod.type` ends in `WEEKLY`, else
  derive it from `end - start` rounded to whole minutes.
- **`productUsage` is a breakdown of that same pool** (57 + 5 + 1 ≈ 63), not
  independent quotas. Rendering each as its own window would imply the user has
  three separate allowances, so do not emit windows for them. Ignore the array
  for now.

Credits, from the `{val:}` objects:
- `balance` = `prepaidBalance.val` formatted with two decimals when non-nil.
- `enabled` = `onDemandCap.val > 0 || prepaidBalance.val > 0`.
- `hasCredits` = `prepaidBalance.val > 0`; `unlimited` = `false`.
- When none of the three keys is present, `credits` is `nil`.

Errors, matching the other providers' tone (tell the user what to *do*):
- No auth file / no token ⇒ `.notConfigured("Sign in with `grok login` — no token in <path>")`
- 401/403 ⇒ `.unauthorized("Grok sign-in expired — run `grok login` to refresh it")`
  (the token lives about six hours, so this will be common)
- other non-2xx ⇒ `QuotaError.forHTTP(status, provider: "Grok")`
- unparseable body ⇒ `.malformed("Unrecognised response from Grok billing endpoint")`

Wiring: append a third `HybridProvider` in `ProviderCatalog.all` after Codex —
`local: nil`, `live: GrokLiveSource()`, `liveEnabled: isLiveEnabled(Grok.providerID)`.

## Out of scope
- Refreshing the Grok token with its `refresh_token`, or writing to
  `~/.grok/auth.json`. An expired token is reported, not fixed.
- `https://grok.com/rest/subscriptions` — the PM checked it; it returns Stripe
  invoice and price identifiers with no usage numbers, and this tool should not
  ingest billing identifiers. Do not call it.
- Auto-top-up, purchasing, or any endpoint that changes state.
- Adding Kimi or DeepInfra — neither has a usable endpoint yet.
- `main.swift`, `ConsoleReport.swift`, Claude, Codex.
- Anything under `App/`, `Widget/`, `Sources/QuotaKit/UI/`.
