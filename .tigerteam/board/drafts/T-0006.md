## Goal
T-0004 concluded there was no way to get live ChatGPT quota. **That conclusion
was wrong**, and this ticket supersedes it. The Codex CLI ships a local
JSON-RPC server that answers a documented `account/rateLimits/read` request —
no bearer token to handle, no bot-protected host, and it returned in **0.24 s**
when the PM measured it.

Verified by hand on this machine:

```
printf '%s\n' \
  '{"method":"initialize","id":1,"params":{"clientInfo":{"name":"quota-check","title":"Quota Check","version":"0.1.0"}}}' \
  '{"method":"initialized"}' \
  '{"method":"account/rateLimits/read","id":2}' \
| codex app-server --stdio
```

Add it as ChatGPT's live source. The rollout reader stays as the local
fallback, so a machine without the `codex` binary still reports.

## Context
- Newline-delimited JSON-RPC over stdio. Three request lines in the order
  above; the reply to `id: 2` carries the payload. Other lines (the `id: 1`
  reply, `remoteControl/status/changed` notifications) must be skipped.
- The real `result.rateLimits`, captured by the PM, is committed as the fixture
  in `scope` — use it, do not invent one.
- **The existing parser already fits.** `Codex.window(from:)` matches both
  spellings via `firstValue(forAnyKey:)` (`usedPercent`/`used_percent`,
  `windowDurationMins`/`window_minutes`, `resetsAt`/`resets_at`), and
  `Codex.snapshot(fromRateLimits:)` already handles `planType`/`plan_type` and
  the `credits` block. Hand it `result.rateLimits` and it should work with **no
  parser changes** — verify this rather than rewriting it.
- `Codex.liveSourceIfConfigured` (the HTTP source behind
  `QUOTA_MONITOR_CODEX_USAGE_URL`) stays exactly as it is. Do not remove it.
- Follow the injection convention in AGENTS.md — the subprocess must be behind
  a seam, because **tests cannot spawn `codex`** under the worker sandbox.

## Design — implement exactly this
```swift
/// Live ChatGPT quota from the Codex CLI's local app-server.
///
/// Preferred over any HTTP route: `account/rateLimits/read` is part of the
/// documented app-server protocol, and it means this tool never handles a
/// ChatGPT bearer token itself.
public struct CodexAppServerSource: QuotaSource {
    public let providerID = Codex.providerID
    public let displayName = Codex.displayName
    public let origin = SnapshotOrigin.live

    /// Runs the three-line JSON-RPC exchange and returns raw stdout.
    /// Injected so tests never spawn a process.
    public typealias Transport = @Sendable () throws -> Data

    public init(transport: Transport? = nil)   // default: the real subprocess
    public func fetch() async throws -> ProviderSnapshot
}
```

Real transport:
- Launch `codex` resolved from `PATH` via `/usr/bin/env codex`, arguments
  `["app-server", "--stdio"]`.
- Write the three request lines (each newline-terminated) to stdin, then close
  stdin.
- Read stdout **to end**, then `waitUntilExit()`. Send stderr to
  `FileHandle.nullDevice`.
- Enforce a **10-second** ceiling: if the process has not exited by then,
  `terminate()` it and throw `.transport("codex app-server timed out")`.
- If the process cannot be launched, throw
  `.notConfigured("Codex CLI not found — install it or run `codex login`")`.

Parsing in `fetch()`:
- Split stdout on newlines; parse each non-empty line as JSON; ignore lines
  that fail to parse.
- Select the object whose `id` equals `2`. Absent ⇒
  `.noDataFound("codex app-server returned no rate limits")`.
- If that object has an `error`, throw `.transport` carrying its `message`.
- Take `result.rateLimits` (address it by **explicit path** — do not use
  `firstValue(forKey:)`; `rateLimitsByLimitId` repeats every key and a
  breadth-first search could return the wrong subtree) and pass it to
  `Codex.snapshot(fromRateLimits:observedAt:origin:)` with `origin: .live`.
- A nil snapshot ⇒ `.malformed("Unrecognised app-server rate limits")`.

Wiring: in `ProviderCatalog.all`, the codex provider's `live` becomes
`Codex.liveSourceIfConfigured ?? CodexAppServerSource()` — an explicit
`QUOTA_MONITOR_CODEX_USAGE_URL` still wins, otherwise the app-server is used.
`local` stays `CodexLocalSource()`.

## Out of scope
- Removing or altering `CodexLiveSource` / `Codex.liveSourceIfConfigured`.
- Changing `CodexLocalSource` or the rollout parser.
- `account/rateLimits/read` is the only app-server method to call. Do not start
  a Codex session, send a prompt, or call any other method — that would spend
  the user's quota to measure it.
- Parsing `rateLimitResetCredits`, `spendControlReached`, or
  `rateLimitsByLimitId`. Useful later; not now.
- Claude, Grok, `main.swift`, `ConsoleReport.swift`.
- Anything under `App/`, `Widget/`, `Sources/QuotaKit/UI/`.
