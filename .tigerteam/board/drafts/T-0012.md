## Goal
Add Grok (xAI) as a Go-only provider: bearer token from `~/.grok/auth.json`,
`GET https://cli-chat-proxy.grok.com/v1/billing?format=credits`, and ONE
weekly window from `config.creditUsagePercent`. First provider that never
existed in Swift.

## Context
- **Read first:** `PROVIDERS.md` § Grok — endpoint, headers, credential
  layout, and why `productUsage` must NOT become three windows.
- Fixture: `grok-billing-credits.json` (real response).
- Pattern to copy: `core/internal/providers/claude/` (LiveSource with
  `BaseURL`, `*http.Client`, injected credential reader).
- Registry: `core/internal/registry/` — append after codex; Local=nil.

## Design — implement exactly this
```go
const ProviderID = "grok"; const DisplayName = "Grok"
func DefaultAuthPath() string  // ~/.grok/auth.json

type Credentials struct{ Token string; ExpiresAt *time.Time }
// ParseCredentials: the top level is a map keyed by OIDC scope; take the FIRST
// key with prefix "https://auth.x.ai::" (sorted for determinism), then that
// object's "key" (bearer) and "expires_at" (jsonx.Time). Explicit path only.
// Do NOT read email or any profile field. Empty → source.NotConfigured("Run `grok login` — no Grok token in <path>").
func ParseCredentials(blob []byte) (Credentials, error)

// Snapshot: window {ID:"credits", Label:"Week", Kind:weekly, UsedPercent:
// config.creditUsagePercent, ResetsAt: config.currentPeriod.end,
// WindowMinutes: minutes between currentPeriod.start and .end when both parse
// (else 10080 when type == "USAGE_PERIOD_TYPE_WEEKLY", else nil)}.
// Credits: only when config.prepaidBalance.val > 0 → {HasCredits:true,
// Unlimited:false, Balance: fmt "%.2f" of val, Enabled:true}; otherwise nil.
// Plan: nil. ok=false when creditUsagePercent is missing.
func Snapshot(root any, observedAt time.Time) (snapshot.Provider, bool)

type LiveSource struct{ BaseURL string /*https://cli-chat-proxy.grok.com*/; Client *http.Client; Credentials func() ([]byte, error) }
// Headers: Authorization: Bearer, x-grok-client-mode: grok-build, Accept: application/json,
// User-Agent: quotamon/0.1. 401/403 → Unauthorized "Grok sign-in expired — run `grok login`"; else source.ForHTTP.
```
Short name for the menu bar / waybar text: `GK` (add to the short-name map
