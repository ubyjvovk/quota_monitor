## Design — implement exactly this
```go
const ProviderID = "kimi"; const DisplayName = "Kimi"
func DefaultCredentialPath() string   // ~/.kimi-code/credentials/kimi-code.json
type Credentials struct{ Token string; ExpiresAt *time.Time }
// ParseCredentials: top-level access_token (explicit key), expires_at via jsonx.Time.
// Empty → source.NotConfigured("Run `kimi` and sign in — no Kimi token in <path>")
func ParseCredentials(blob []byte) (Credentials, error)

// Snapshot from the /usages body:
//   window 1: from root.usage → ID "weekly", Label "Week", Kind weekly, WindowMinutes 10080,
//             UsedPercent = used/limit*100 (both are STRINGS — strconv.ParseFloat), ResetsAt = resetTime
//   then one window per root.limits[i]: minutes = window.duration × (1 if TIME_UNIT_MINUTE, 60 if TIME_UNIT_HOUR,
//             1440 if TIME_UNIT_DAY; skip unknown units), ID = fmt "limit_%dm", Label/Kind from
//             snapshot.LabelFromMinutes/KindFromMinutes, percent from detail.used/limit, ResetsAt detail.resetTime.
//   limit "0" or unparsable → skip that window (never divide by zero, never invent a percentage).
//   Plan: user.membership.level with the "LEVEL_" prefix stripped and lower-cased ("basic"); nil if absent.
//   Credits: nil. Never copy user.userId anywhere.
func Snapshot(root any, observedAt time.Time) (snapshot.Provider, bool)   // ok=false when no windows

type LiveSource struct{ BaseURL string /*https://api.kimi.com/coding/v1*/; Client *http.Client; Credentials func() ([]byte, error) }
// GET {BaseURL}/usages, headers Authorization: Bearer, Accept: application/json, User-Agent: quotamon/0.1.
// 401/403 → source.Unauthorized("Kimi sign-in expired — run `kimi` once to refresh it") (the token lives 15 min;
// mention that in the doc comment). Other non-2xx → source.ForHTTP. No windows → Malformed.
```
