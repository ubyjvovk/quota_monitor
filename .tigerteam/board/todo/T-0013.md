## Goal
Add DeepInfra as a Go-only provider. It is pay-as-you-go: the honest
readout is month-to-date spend, and a percentage exists ONLY when the
account has a spending limit set. Never invent a percentage.

## Context
- **Read first:** `PROVIDERS.md` § DeepInfra (endpoints are NOT under `/v1`;
  `total_cost` is cents; `interval` is epoch ms; `limit` negative = none).
- Fixture: `deepinfra-usage.json`. Key: env `DEEPINFRA_KEY` — **read from
  the environment only**; the repo's `.env` is masked from you on purpose,
  and the code must not learn to parse it.
- Pattern: `core/internal/providers/grok/` or `claude/`.

## Design — implement exactly this
```go
const ProviderID = "deepinfra"; const DisplayName = "DeepInfra"

type LiveSource struct{ BaseURL string /*https://api.deepinfra.com*/; Client *http.Client; Key func() string /*os.Getenv("DEEPINFRA_KEY")*/ }
// Fetch: empty key → source.NotConfigured("Set DEEPINFRA_KEY to read DeepInfra spend").
// Two GETs with Authorization: Bearer <key>, Accept: application/json, User-Agent: quotamon/0.1:
//   /payment/config          → limit (float, USD; <= 0 means no limit)
//   /payment/usage?from=current → months[0]: total_cost (cents), interval.to (ms)
// A 401/403 on either → Unauthorized("DeepInfra rejected DEEPINFRA_KEY").

// Snapshot(limitUSD float64, hasLimit bool, spentUSD float64, periodEnd *time.Time, observedAt):
//   hasLimit && limitUSD > 0 → one window {ID:"monthly_spend", Label:"Month", Kind:monthly,
//       UsedPercent: spent/limit*100, ResetsAt: periodEnd, WindowMinutes: nil}
//   otherwise → NO windows (a provider with no ceiling has no percentage).
//   Always: Credits{HasCredits:false, Unlimited:!hasLimit, Balance:"$7.75 this month" style
//       string fmt "$%.2f this month", Enabled:true}; Plan "pay-as-you-go";
//   Status: OK in both cases. The CLI already renders a windowless provider as "—".
```
Short name `DI` — add it to `providerShortName` in `core/cmd/quotamon/waybar.go` (in scope).
