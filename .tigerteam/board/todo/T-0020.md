## Goal
`quotamon` prints `credits 0 (not enabled)` for ChatGPT. Swift's reference
(`creditsLine` in `QuotaKit/Sources/QuotaKit/Support/ConsoleReport.swift`)
omits the line when a disabled credit has no meaningful balance; the Go
renderer should match.

## Context
- `core/cmd/quotamon/table.go` (T-0015) — the credits-line helper.
- Rule set for reference: `unlimited` with balance → balance verbatim;
  `unlimited` without → "unlimited"; enabled with balance → "<balance>
  remaining"; disabled with a non-zero balance → "<balance> (not enabled)".

## Design — implement exactly this
A credit with `Enabled == false` whose `Balance` is nil, empty, or parses as
numerically zero (`"0"`, `"0.00"`, `"0,00"` — trim currency symbols/spaces
before parsing) prints **no** credits line. Everything else unchanged.
