## Goal
Two things the user asked for, in one ticket because they meet in the hybrid
layer:
1. **Kimi refresh.** The access token lives 15 minutes. `PROVIDERS.md` § Kimi
   now documents the verified refresh exchange; implement it natively, and
   write the rotated pair back to the CLI's credential file.
2. **Refresh less often.** A stale token means the vendor CLI has not run, so
   nothing was spent: keep the last good reading per provider on disk and
   reuse it (labelled cached) instead of refreshing, until it is older than
   the provider's shortest window.

## Design — implement exactly this
### Kimi refresh (`providers/kimi`)
```go
type CredentialStore struct { Path string }                       // default DefaultCredentialPath()
func (s CredentialStore) Load() (Credentials, error)               // full file: access_token, refresh_token, expires_at (s), expires_in, scope, token_type
func (s CredentialStore) Save(c Credentials) error                 // temp file + rename, 0600, same keys; expires_at = now + expires_in
type Refresher struct { TokenURL string /*https://auth.kimi.com/api/oauth/token*/; ClientID string /*17e5f671-d194-4dfb-9706-5516cb48c098*/; Client *http.Client }
func (r Refresher) Refresh(ctx, refreshToken string) (Credentials, error)   // form POST per PROVIDERS.md; headers Content-Type, Accept, User-Agent: quotamon/0.1
```
`LiveSource` gains `Store CredentialStore`, `Refresher *Refresher`, `Now func() time.Time`.
Fetch: load; if `expires_at <= now+30s` → Refresh, Save, use the new token.
On 401 from `/usages` with a token that was NOT just refreshed → refresh once
and retry once; a 401 after refresh, or a 4xx from the token endpoint →
`source.Unauthorized("Kimi sign-in expired — run `kimi login`")`. Never write
the file unless the refresh succeeded. Never log tokens.

### Last-reading cache (`core/internal/cache`)
```go
type Store struct { Dir string }                       // default: filepath.Dir(config.Path())
func (s Store) Load(providerID string) (snapshot.Provider, bool)
func (s Store) Save(p snapshot.Provider) error           // <dir>/cache/<id>.json, 0600, atomic
```
### Hybrid policy (`hybrid.Provider` gains `Cache *cache.Store`, `ShortestWindow time.Duration`, `TokenStale func(now) bool` — all optional)
Before fetching live: if `TokenStale != nil && TokenStale(now)` and a cached
reading exists whose `ObservedAt` is younger than `ShortestWindow` and which
still has a current window → return it with `Origin: local` and status
`OK` (the table/tooltip already print `cached · <age>`); **do not** call live.
Otherwise proceed as today; after a successful live fetch, `Cache.Save`.
Registry wires it for every provider (`ShortestWindow`: 5h for claude/codex/
kimi, 7d for grok, 30d for deepinfra; `TokenStale` only for kimi — Grok's
token is also time-limited (~6 h): wire it too using `ParseCredentials(...).ExpiresAt`).
`--no-live` behaviour unchanged. Add `quotamon --fresh` (also `snapshot --fresh`)
to bypass the cache and force a refresh.
