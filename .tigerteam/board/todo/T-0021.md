## Goal
The bare `quotamon` table is functional but misaligned and hard to scan. The
user chose: **aligned columns + an inline usage bar per window + optional
colour**. Current defects to fix on the way: padding counts bytes so the `—`
plan placeholder shifts the row; `pay-as-you-go` overflows the plan column;
providers run together with no separator; `check` prints "1 windows".

## Context
- Renderer: `core/cmd/quotamon/table.go` (T-0015/T-0020). Formatting helpers:
  `core/internal/format/`. Keep the credits-line rules from T-0020 intact.
- Current output on the reference machine (bytes-padded, note the shifted Grok row):
  ```
  Claude          max    live · just now
    Fable wk          23%  resets in 1d 16h
  Grok            —      live · just now
  DeepInfra       pay-as-you-go live · just now
  ```
- Severity thresholds are shared with waybar/Swift: <70 normal, <90 warning,
  ≥90 critical (`severity()` in `waybar.go` — reuse, do not duplicate the numbers).

## Design — implement exactly this
Layout (widths in terminal cells; pad with `utf8.RuneCountInString`, never `len`):
```
Claude       max            live · just now
  Fave wk   ████▓░░░░░░░░░░░░░░░  23%  1d 16h
  Week      ███░░░░░░░░░░░░░░░░░  15%  1d 16h
  5h        █░░░░░░░░░░░░░░░░░░░   6%  2h 39m
  credits   20.00 (not enabled)

ChatGPT      plus           live · just now
  5h        ████████████████████ 100%  8m
  Week      ██████░░░░░░░░░░░░░░  31%  5d 11h

Grok         —              live · just now
  Week      █████████████░░░░░░░  63%  2d 13h

DeepInfra    pay-as-you-go  live · just now
  spend     $7.96 this month
```
- Header: name left-padded to 12, plan to 14 (`—` when nil; never truncate —
  if longer, let it push the origin column right for that row only), then
  `<origin word> · <age>`. Blank line between providers; none after the last.
- Window row: 2-space indent, label padded to 9 (truncate with `…` at 9),
  a **20-cell bar**, percent right-aligned in 4 cells (`100%`), then the
  countdown (`format.Countdown`, without the words "resets in"; `—` when no
  reading; `reset` when the window has rolled over).
- Bar: `filled = round(pct/5)`, capped at 20; filled cells `█`, empty `░`;
  no reading → 20 × `░` and percent `—`. Percent over 100 fills all 20.
- Credits row: label `credits` (or `spend` when `Unlimited && Balance != nil`,
  i.e. the DeepInfra case), then the T-0020 text rules.
- `check`: pluralise correctly (`1 window`, `2 windows`).

Colour (default **auto**): `--color=auto|always|never` flag and `NO_COLOR`
env (any value → never; see no-color.org). `auto` = on only when stdout is a
terminal (`os.Stdout.Stat()` mode has `os.ModeCharDevice`). When on, colour
**only the filled bar cells and the percent** by severity: normal → default
colour (no SGR), warning → `\x1b[33m`, critical → `\x1b[31m`; reset with
`\x1b[0m`. Nothing else is coloured. Colour never changes column widths.
Put the ANSI logic in `core/internal/format/color.go` (`Colorize(sev, s)`),
so waybar/JSON never see escapes.
