## Goal
The status-bar icon stacks one bar per provider, currently in
`rankedProviders` order (most constrained on top). The panel below it lists
providers in snapshot order (the console's fixed registry order), so the
bars and the rows disagree — the user reads bar 1 as Claude and it is not.
Draw the bars in snapshot order, top to bottom, exactly matching the panel.

## Context
- `App/MenuBarIcon.swift` — `image(for:now:)`; the only line that decides
  order is `let providers = snapshot.rankedProviders(asOf: now)`.
- The panel renders `ConsoleTable.render(engine.snapshot.providers, asOf:)`
  (`App/QuotaPanelView.swift`) — snapshot order. `QuotaFormat.menuBarTitle`
  (the icon's accessibility description) already iterates `snapshot.providers`.
- Your lane cannot run `xcodebuild`; the PM builds and re-renders
  `docs/menubar.png` at review.
