## Goal
`quotamon` typed bare at a prompt should show all quotas at once, the way
`swift run quotactl` does today. `snapshot` (JSON) and `waybar` stay as they
are; this adds the default human view and a `--json` alias.

## Context
- Port the layout of `QuotaKit/Sources/QuotaKit/Support/ConsoleReport.swift`
  (`render`, `windowLine`, `creditsLine`, `originTag`) — read it, it is short
  and every rule in it was learned from a real bug.
- `renderWaybar`/`providerTooltip` in `core/cmd/quotamon/waybar.go` already
  compute most of the strings; reuse `format.Percent/Countdown/Age`.
- Providers by then: claude, codex, grok, deepinfra (T-0012/T-0013).

## Design — implement exactly this
```
quotamon [--no-live]          → table below, exit 0 if any provider has a window, else 1
quotamon --json [--no-live]   → identical to `quotamon snapshot`
```
Table, one block per provider in registry order, 2-space indent:
```
<DisplayName padded 15> <plan or —, padded 6> ... <origin word> · <age>
  <label padded 14> <percent right-aligned 6, "—" when no reading>  resets in <countdown> | window reset | (nothing when no resetsAt)
  credits        <line per creditsLine rules>          (omitted when creditsLine is nil)
  !  <status message>                                  (only when status.state != ok)
```
`creditsLine` rules (from Swift): `unlimited` → "unlimited"; enabled with
balance → "<balance> remaining"; !enabled with a non-empty balance →
"<balance> (not enabled)"; !enabled and no balance → omit the line.
For DeepInfra the balance is already the "$7.75 this month" string, and it is
Enabled+Unlimited when no limit exists → render "$7.75 this month" (special-case:
when Unlimited and Balance != nil, print the balance verbatim instead of "unlimited").
Windows sorted most-constrained first (reading > no reading, then percent desc,
then kind rank) — add `snapshot.Provider.SortedWindows(now)` if it does not exist
(scope allows `core/internal/snapshot/` for that one function — list it in the report).
Origin word: live→"live", local→"cached", unavailable→"unavailable".
