## Goal
On 2026-08-31 16:07 the user's real `~/.config/quotamon/config.json` was
deleted while wave test suites were being run unsandboxed on the host (PM
review runs bypass Seatbelt). The culprit test was not conclusively
identified; the systemic fix is that the test entrypoint must make real-config
access impossible for everything under it.

## Design — implement exactly this
At the top of `scripts/test-all.sh` (after `set -u`/cd): when
`QUOTA_MONITOR_DIR` is unset or empty, export
`QUOTA_MONITOR_DIR="$(mktemp -d "${TMPDIR:-/tmp}/quotamon-tests.XXXXXX")"` and
remove it on exit via trap. Also export `QUOTA_MONITOR_RENDER=""`? — no, do
NOT touch other vars. A comment records the 2026-08-31 incident in one line
(config deleted by an unsandboxed suite run) — why, not what.

- [ ] `grep -n "QUOTA_MONITOR_DIR" scripts/test-all.sh` shows the guard + trap
