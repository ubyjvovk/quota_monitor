## Goal
The owner looked at T-0080 on a real Omarchy box: *"a total mess, all over the
place, like 6 different typographics."* That is the card idiom itself —
`Style.font.display` for the hero, `body` for labels, `caption` for meta /
percent / countdown / badge, bold on the badge, uppercase from `PanelHero` —
every element at its own scale. The owner's decision, superseding the T-0080
direction: **make the panel look like the console / Mac dropdown, and respect
the theme.**

The console look is the opposite of the card look: **one font, one size,
colour is the only thing that varies**, and every colour is a theme role.

```
Claude       max            live · just now
  Fable wk  █████░░░░░░░░░░░░░░░  23%  1d 16h
  Week      ███░░░░░░░░░░░░░░░░░  15%  1d 16h
  5h        █░░░░░░░░░░░░░░░░░░░   6%  2h 39m
  credits   20.00 (not enabled)

ChatGPT      plus           live · just now
  5h        ████████████████████ 100%  8m
  Week      ██████░░░░░░░░░░░░░░  31%  5d 11h
```

That is `quotamon --demo`, byte for byte. The plugin will render exactly that
text, split into colour runs, in a monospace grid.

## Context — read before designing
- **The layout already exists twice, and the second copy is your reference.**
  `core/cmd/quotamon/table.go` (~180 lines: `renderTableProvider`,
  `renderTableWindow`, `renderTableBar`, `tableCountdown`, `padTableCell`,
  `truncateAndPadTableCell`, `creditLines`, `tableOrigin`) is the source of
  truth. `QuotaKit/Sources/QuotaKit/Support/ConsoleTable.swift` is a Swift port
  of it that the Mac app renders: it produces `[Line]`, each `Line` a list of
  `Span { text, tone }`, `Tone ∈ { plain, warning, critical }`, split *only*
  where the colour role changes; a provider separator is a `Line` with no
  spans. **Port that model to JavaScript.** Read both files first; do not
  invent a layout.
- **It is golden-pinned.** `QuotaKit/Tests/QuotaKitTests/ConsoleTableTests.swift`
  renders `Fixtures/quotamon-demo.json` with `asOf: snapshot.generatedAt`
  (`2026-08-30T14:32:27Z`, so every age reads `just now`) and compares the
  joined text to a literal. Your test does the same with the same fixture, the
  same `now`, and the same literal. When `table.go` changes, all three goldens
  break together — that is the mechanism that keeps three copies honest.
- **Theme roles** (from Omarchy's `qs.Commons` `Color`): `foreground`,
  `background`, `accent`, `urgent`, `muted`, plus `popups.text` /
  `popups.background` / `popups.border`. There is no "warning" role. The panel
  today derives `dim` as `Qt.darker(foreground, 1.55)` — a fake theme colour —
  and T-0080 added two hex literals (`#879A39`, `#d0772b`). All of that goes.
- The panel's existing root properties `foreground`, `urgent`, `fontFamily`
  come from the bar or `Color`/`Style` and stay. `Model.iconBars`,
  `providerRows`, `providerMeta`, `creditsText`, the manifest read,
  `installQuotamon`, the watchdogs, and the Refresh / Install / Update
  `Button`s are **not** part of this change.
- **Fixture path from the plugin's tests.** `model_test.mjs` ships in the
  standalone plugin repository, where `../QuotaKit/...` and `../VERSION` do not
  exist. Read them if present and print a one-line skip note if absent, so the
  file is honest in both places. Apply the same treatment to the existing
  `../VERSION` read.
- Nobody on this board can run the QML. The owner will eyeball it from plugin
  `master` under `--no-tag`. Keep the QML simple enough that a careful read is
  a review.

## Design (decided; implement exactly this)

**1. `Model.js` — the port**

```js
// Port of core/cmd/quotamon/table.go, matching ConsoleTable.swift.
// Returns [{ spans: [{ text, tone }] }]; a separator line has spans: [].
// tone ∈ "plain" | "dim" | "warning" | "critical"
function consoleLines(snapshot, nowMs)

// The spans of every line joined, lines joined by "\n" — the golden surface.
function consoleText(snapshot, nowMs)
```

- Reproduce `table.go` exactly: 12-wide name, 14-wide plan (`—` when absent),
  `origin · age`; two-space indent, 9-wide truncated label, a 20-cell bar of
  `█` and `░`, right-aligned percent in 4 cells (`—` without a reading), two
  spaces, countdown; `creditLines` verbatim; a `  !  <message>` line when
  `status.state !== "ok"`; one empty separator line between providers, none
  after the last. Use the existing `formatAge` / `formatCountdown` /
  `currentUsedPercent` / `severity` helpers where they already match the Go
  output **exactly**; where they differ (the Go countdown has no `resets in `
  prefix, for instance), write a table-specific helper rather than changing a
  function other tests pin.
- Tones — the fourth is an extension over Swift's three, for the theme:
  - the percent cell and the filled `█` run: `severity(percent)` →
    `normal → "plain"`, `warning → "warning"`, `critical → "critical"`;
  - the unfilled `░` run: `"dim"`;
  - the `  !  ` status line: `"critical"`;
  - everything else: `"plain"`.
  Split spans only where the tone changes, as Swift does.
- `consoleText` is `lines.map(l => l.spans.map(s => s.text).join("")).join("\n")`.

**2. `Panel.qml` — the render**

- Delete: `PanelHero` usage for providers, the badge `iconComponent`,
  `component WindowRow`, `severityColor`, the per-provider status `Text`, and
  the provider `Repeater`'s `Column`. Add a comment at the top of the console
  block naming `Model.consoleLines` as the only source of layout.
- Add one root function, the **only** place colour is decided:
  ```qml
  function toneColor(tone) {
    if (tone === "critical") return Color.urgent
    if (tone === "warning")  return Color.accent
    if (tone === "dim")      return Color.muted
    return root.foreground
  }
  ```
  `dim` on the root becomes `Color.muted`. **Zero hex literals** anywhere in
  the file — `grep -nE "#[0-9a-fA-F]{6}" omarchy/Panel.qml` must return
  nothing.
- Render `Model.consoleLines(root.snapshot, root.nowMs)` as a `Column` (spacing
  0) of one `Row` per line (spacing 0); each `Row` holds a `Repeater` over the
  line's spans producing `Text { text: span.text; color: root.toneColor(span.tone);
  font.family: root.fontFamily; font.pixelSize: Style.font.body }`. A separator
  line (no spans) renders as an `Item` whose height equals one text line
  (measure a hidden `Text` once and reuse its `implicitHeight`).
- **Every piece of text in the panel** — the console block, the status /
  version warning line, the version footer — uses `root.fontFamily` at
  `Style.font.body`. No `display`, no `caption`, no `bold`. The Refresh /
  Install / Update `Button`s keep Omarchy's own control styling; they are
  controls, not content.
- The version footer becomes one `dim` console-style line (`aboutText` output,
  unchanged text) in the same font and size.
- The empty state (`rows.length === 0`) keeps its message and the Install
  button, in the same font and size.
- Do not touch the `Panel` shell, its width/anchoring, the flickable, the
  buttons' `onClicked`, or anything below the console block other than the
  font/size/colour normalisation above.

**3. `model_test.mjs`**

- Golden: load `../QuotaKit/Tests/QuotaKitTests/Fixtures/quotamon-demo.json`
  if it exists (skip with a printed note if not), render with
  `nowMs = Date.parse(snapshot.generatedAt)`, and `assert.equal` the result of
  `consoleText` to the literal copied **verbatim** from
  `ConsoleTableTests.swift`'s `golden` (all 20-odd lines). Do not retype it —
  copy it; a single trailing space breaks the point of the test.
- Span tests on constructed snapshots: a window at 6% → `█` run `"plain"`,
  `░` run `"dim"`, percent `"plain"`; at 85% → `"warning"` on bar fill and
  percent; at 100% → `"critical"`, no `░` run at all; a `needsSetup` status →
  a `  !  ` line whose single span is `"critical"`; two providers → exactly one
  separator line with `spans.length === 0` between them and none trailing; a
  provider with `plan: null` → the `—` cell.
- The `../VERSION` read gains the same exists-or-skip guard.
- Every existing assertion still passes unmodified. List any you had to change
  and why.

**4. `omarchy/README.md`**

Replace the dropdown description: the panel renders the same console table as
`quotamon` and the macOS app, in the shell's font, coloured only by theme roles
(`foreground`, `muted`, `accent` for warning, `urgent` for critical). Note that
the table assumes the shell font is fixed-pitch, which Omarchy's default is.
