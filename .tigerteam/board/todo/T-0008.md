### `snapshot` package
```go
type Kind string    // "session" | "weekly" | "monthly" | "other"
type Origin string  // "live" | "local" | "unavailable"

// Time marshals as RFC 3339 in UTC with NO fractional seconds:
// "2026-08-29T18:59:59Z". Swift's .iso8601 decoder REJECTS fractional
// seconds, so this is the single most important line in the file.
// Unmarshal must accept fractional seconds and offsets (time.RFC3339Nano).
type Time struct{ time.Time }

type Window struct {
    ID            string  `json:"id"`
    Label         string  `json:"label"`
    Kind          Kind    `json:"kind"`
    UsedPercent   float64 `json:"usedPercent"`
    ResetsAt      *Time   `json:"resetsAt,omitempty"`
    WindowMinutes *int    `json:"windowMinutes,omitempty"`
}
// CurrentUsedPercent returns ok=false once ResetsAt <= now: a rolled-over
// window has NO reading (never 0) — see AGENTS.md gotcha 5.
func (w Window) CurrentUsedPercent(now time.Time) (float64, bool)
func KindFromMinutes(minutes *int) Kind      // mirror QuotaWindow.Kind.inferred
func LabelFromMinutes(minutes *int) string   // mirror QuotaWindow.label(forMinutes:)

type Credits struct {
    HasCredits bool    `json:"hasCredits"`
    Unlimited  bool    `json:"unlimited"`
    Balance    *string `json:"balance,omitempty"`
    Enabled    bool    `json:"enabled"`
}

// Status v2 (decided in GO-PORT.md "One known wrinkle"):
//   {"state":"ok"} | {"state":"needsSetup","message":"…"} | {"state":"failed","message":"…"}
type Status struct {
    State   string `json:"state"`             // "ok" | "needsSetup" | "failed"
    Message string `json:"message,omitempty"`
}
func OK() Status; func NeedsSetup(msg string) Status; func Failed(msg string) Status

type Provider struct {
    ID          string   `json:"id"`
    DisplayName string   `json:"displayName"`
    Plan        *string  `json:"plan,omitempty"`
    Windows     []Window `json:"windows"`      // always a JSON array, never null
    Credits     *Credits `json:"credits,omitempty"`
    ObservedAt  Time     `json:"observedAt"`
    Origin      Origin   `json:"origin"`
    Status      Status   `json:"status"`
}
func Unavailable(id, displayName string, status Status, observedAt time.Time) Provider
// TightestWindow: among windows with a current reading, highest percent;
// ties by Kind rank session<weekly<monthly<other. ok=false when none.
func (p Provider) TightestWindow(now time.Time) (Window, bool)

type Snapshot struct {
    Providers   []Provider `json:"providers"`  // always an array
    GeneratedAt Time       `json:"generatedAt"`
}
func (s Snapshot) Encode() ([]byte, error)   // json.MarshalIndent, 2 spaces
func Decode(b []byte) (Snapshot, error)
```
Ensure `Windows == nil` still encodes as `[]` (normalise in Encode or a
MarshalJSON on Provider).

### `source` package
```go
type Source interface {
    ProviderID() string
    DisplayName() string
    Origin() snapshot.Origin
    Fetch(ctx context.Context) (snapshot.Provider, error)
}
type ErrorKind int
const (   // numeric value == reporting priority, higher wins (QuotaSource.swift)
    NotConfigured ErrorKind = iota // 0: optional fallback nobody asked for
    NoDataFound                    // 1
    Transport                      // 2: transient
    Malformed                      // 3
    Unauthorized                   // 4: actionable and the real blocker
)
type Error struct{ Kind ErrorKind; Message string }
func (e *Error) Error() string { return e.Message }
func Errorf(kind ErrorKind, format string, a ...any) *Error
func ForHTTP(status int, provider string) *Error   // port QuotaError.forHTTP verbatim (401/403 → Unauthorized, 429 & 5xx → Transport, else Transport)
func Priority(err error) int                        // *Error → Kind; other errors → 2
```

### `jsonx` package
Explicit-path helpers over `any` from `encoding/json` (`map[string]any`,
`[]any`, `float64`, `string`, `bool`, `nil`). **No recursive key search
anywhere** — PROVIDERS.md rule 3.
```go
func Parse(b []byte) (any, error)
func Get(v any, path ...string) (any, bool)   // walks maps only; missing/nil → false
func String(v any) (string, bool)
func Float(v any) (float64, bool)             // float64 only
func Int(v any) (int, bool)                   // float64 with integral value
func Bool(v any) (bool, bool)
// Time coerces every timestamp shape in PROVIDERS.md rule 2:
//   float64/int  > 1e11  → epoch milliseconds
//   float64/int <= 1e11  → epoch seconds
//   string               → RFC 3339 (fractional seconds and offsets accepted)
func Time(v any) (time.Time, bool)
```

### `quotamon` binary (skeleton)
`quotamon snapshot` prints `Snapshot{Providers: []}` with `GeneratedAt` now,
exit 0. `quotamon --help`/`-h`/no args prints usage listing `snapshot`,
`waybar`, `check` (the latter two print "not implemented" and exit 2 for
now). Unknown subcommand → usage on stderr, exit 2. T-0011 fills these in.

### `core/Makefile`
`build` → `bin/quotamon` for the host; `test` → `go vet ./... && go test ./...`;
`matrix` → `bin/quotamon-darwin-arm64`, `bin/quotamon-linux-amd64`,
`bin/quotamon-linux-arm64` via `CGO_ENABLED=0 GOOS=… GOARCH=… go build
-trimpath -ldflags="-s -w"`. `bin/` is already gitignored.

### Swift side: accept status v2, emit status v2
In `ProviderSnapshot.swift`, give `ProviderStatus` a hand-written
`Codable`:
- **encode** → v2: `{"state":"ok"}`, `{"state":"needsSetup","message":m}`,
  `{"state":"failed","message":m}`.
- **decode** → accept v2 **and** the legacy synthesized shape
  (`{"ok":{}}`, `{"needsSetup":{"_0":"m"}}`, `{"failed":{"_0":"m"}}`) so
  snapshots persisted by today's app keep loading. Unknown → throw.
Do not touch any other type in that file.

### Golden fixture `snapshot-v2.json`
Hand-write one snapshot with two providers: (a) `claude`, plan `"max"`,
three windows (one with `resetsAt` and `windowMinutes`, one with neither),
credits `{hasCredits:false, unlimited:false, balance:"20.00", enabled:false}`,
origin `live`, status ok; (b) `kimi` via `Unavailable(...)` — no plan, no
credits, `windows: []`, status `needsSetup` with a message. Keys sorted,
2-space indent, timestamps like `2026-08-29T18:59:59Z`.
