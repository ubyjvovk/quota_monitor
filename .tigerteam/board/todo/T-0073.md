## Goal
The Go core owns quota fetching. The Swift fetchers under
`QuotaKit/Sources/QuotaKit/Providers/` and the `quotactl` diagnostic CLI were
the port's reference semantics and parity oracle; the port is finished, so they
are now a second, unreachable implementation of the same behaviour that every
future provider change would have to be kept honest against. The owner has
asked for them gone.

They are **already dead at runtime** — this ticket removes code the shipping
app cannot reach, it does not change behaviour.

## Context — the PM's survey (do not re-derive)

- `QuotaEngine.refresh(fresh:)` returns early whenever `runner` is non-nil:

```swift
if let runner {
    do { let freshSnapshot = try await runner.snapshot(fresh: fresh); accept(freshSnapshot); lastError = nil }
    catch { lastError = error.localizedDescription }
    return
}
let providers = makeProviders()   // <- everything below here is unreachable in the app
```

- The only real engine in the app is `QuotaEngine(runner: CoreBinary.runner)`
  (`App/QuotaMonitorApp.swift:10`), so the runner is always present. The other
  construction site is `QuotaEngine(preview:)` (`App/DesignSnapshot.swift:38`),
  which sets `runner = nil` and exists for SwiftUI previews and design
  rendering — it never refreshes.
- A symbol-by-symbol reference scan across `QuotaKit/Sources`, `App/`,
  `Widget/` and `QuotaKit/Tests` shows the whole `Providers/` layer
  (`ClaudeLiveSource`, `ClaudeLocalSource`, `CodexLiveSource`,
  `CodexLocalSource`, `ProviderCatalog`, `HybridProvider`, `QuotaSource`,
  `QuotaError`) is referenced **only** by the library itself, its own tests,
  and `quotactl`. Neither `App/` nor `Widget/` touches any of it. The `Claude`
  and `Keychain` hits in `App/` are prose in comments and UI strings, not type
  references — check them yourself before believing me.
- Cascade once `Providers/` and `quotactl` go:
  - `Support/ConsoleReport.swift` — referenced only by the tests and `quotactl`.
  - `Support/Keychain.swift` — referenced only by `Providers/`,
    `ConsoleReport.swift` and the tests.
  - `Support/JSONValue.swift` — referenced only by `Providers/`.
- `UI/PreviewData.swift` uses `Claude.providerID` and `Codex.providerID`, which
  disappear with `Providers/`.
- `QuotaKitTests.swift` holds 68 of the suite's 95 tests and is overwhelmingly
  the provider suite. `ConsoleTableTests` (7), `ConsoleWidgetTests` (8) and
  `QuotamonRunnerTests` (12) test surviving code and must keep passing.
- The Xcode app and widget are **not** built by `swift build`. No worker on
  this board can build them; the PM builds and verifies them at review. Your
  job is to leave the library correct and the package green.

## Design (decided; implement exactly this)

1. Delete, in full: the four files under `QuotaKit/Sources/QuotaKit/Providers/`,
   `QuotaKit/Sources/quotactl/main.swift`, and
   `QuotaKit/Sources/QuotaKit/Support/{ConsoleReport,Keychain,JSONValue}.swift`.
2. `QuotaKit/Package.swift`: drop the `quotactl` executable product and its
   `executableTarget`. Leave the library target, the test target and the
   `resources: [.copy("Fixtures")]` line exactly as they are.
3. `QuotaEngine.swift`: delete `makeProviders()` and the entire
   provider-fetching tail of `refresh(fresh:)`. Keep `runner` optional — the
   preview initialiser depends on nil. Restructure so a nil runner is an
   explicit, reported state rather than silence:

```swift
guard let runner else {
    lastError = "No quotamon runner configured"
    return
}
```

   Everything else in the file — `accept`, history recording, the store, the
   auto-refresh task, `samples(provider:window:)` — stays untouched.
4. `PreviewData.swift`: replace `Claude.providerID` with the literal `"claude"`
   and `Codex.providerID` with `"codex"`. These are the ids the Go core emits;
   `core/internal/providers/claude` and `.../codex` define them as `ProviderID`.
   Do not invent new ids and do not change any other preview value.
5. `QuotaKitTests.swift`: remove every test whose subject you just deleted.
   Keep every test that exercises surviving code — the models
   (`QuotaSnapshot`, `ProviderSnapshot`, `QuotaWindow`, `UsageSample`),
   `QuotaFormat`, and anything else that still compiles and still means
   something. **Do not delete the file wholesale**, and do not weaken a
   surviving test to make it pass. Report the before/after test count.
