## Goal
codex F12 (see `.tigerteam/reviews/2026-08-31-codex.md`): nothing bounds a
fetch; a hung child latches `refreshing` forever and disables Refresh.

## Design — implement exactly this
- A watchdog Timer armed when a fetch starts (30 s): on expiry, if
  `fetchProc.running`, call `fetchProc.signal(SIGTERM)`-equivalent (Quickshell
  Process API — use what exists: `running = false` forces kill if no signal
  API; document which), set `lastError = "quotamon timed out after 30s"`,
  clear `refreshing`, KEEP the previous snapshot. Disarm on normal onExited.
- The existing onExited path must handle the killed process (non-zero exit)
  without double-reporting (watchdog message wins).
- README: one line documenting the 30 s bound.
