## Goal
Port Claude quota reading to the Go core: credential via the `security` CLI
(macOS) or a plain file (Linux), the `limits`-array parser with the legacy
statusline-mirror fallback, `spend`-based credits honouring `enabled`, and
the two sources (local mirror, live HTTP). Semantics are the Swift
implementation's; the fixtures prove parity.

## Context
- **Read first:** `PROVIDERS.md` § Claude and § cross-cutting rules;
  `GO-PORT.md` § Credentials. Then the Swift reference,
  `QuotaKit/Sources/QuotaKit/Providers/ClaudeSources.swift` (292 lines) —
  port its behaviour, including the *why* comments, which record real bugs.
- Foundation from T-0008: `core/internal/snapshot`, `core/internal/source`,
  `core/internal/jsonx`, `core/internal/fixtures`. Use `jsonx.Get` with
  explicit paths; never a recursive key search.
- Fixtures: `claude-usage-live.json` (real live response),
  `claude-mirror.json` (statusline mirror shape).
- Tests must never spawn `security`, hit the network, or read `$HOME` —
  inject (AGENTS.md gotcha 3). Use `net/http/httptest` for the live source.

## Design — implement exactly this
Package `core/internal/providers/claude`:
```go
const ProviderID = "claude"; const DisplayName = "Claude"
const KeychainService = "Claude Code-credentials"

// DefaultMirrorPath: $QUOTA_MONITOR_DIR/claude-usage.json, else ~/.quota-monitor/claude-usage.json
func DefaultMirrorPath() string

// ReadCredentials returns the raw credential JSON for the current OS:
//   darwin: exec /usr/bin/security find-generic-password -s KeychainService -w
//           exit 44 → source.NotConfigured ("No Claude credentials in the Keychain — run `claude` and sign in")
//           exit 51/128 → source.Unauthorized ("Keychain access denied — …")
//           other non-zero → source.Transport
//   linux (and everything else): read ~/.claude/.credentials.json; missing → NotConfigured
// Both paths are behind a func var so tests inject.
func ReadCredentials() ([]byte, error)

type Credentials struct{ Token string; ExpiresAt *time.Time; Plan string }
// ParseCredentials reads ONLY claudeAiOauth.accessToken / .expiresAt (epoch ms)
// / .subscriptionType, falling back to the same keys at the top level. Empty
// token → source.NotConfigured("No Claude access token — run `claude` and sign in").
func ParseCredentials(blob []byte) (Credentials, error)

// Windows: prefer root["limits"] (array). For each entry with string kind,
// string group, numeric percent:
//   group=="session"      → id=kind, label "5h",  Kind session, WindowMinutes 300
//   kind=="weekly_all"    → label "Week", weekly, 10080
//   kind=="weekly_scoped" → label "<scope.model.display_name> wk" or "Week (scoped)", weekly, 10080
//   anything else         → skipped (this is what drops the codenamed buckets)
//   resets_at via jsonx.Time
// If no usable limits array → legacy: root["five_hour"] (id five_hour, "5h", session, 300)
// and root["seven_day"] (id seven_day, "Week", weekly, 10080), percent from the
// first present of used_percentage | usedPercentage | used_percent | utilization
// on that node ONLY; resets_at | resetsAt | reset_at likewise.
func Windows(root any) []snapshot.Window

// Snapshot builds the provider from a rate-limits object. Credits from
// root["spend"]: enabled = spend.enabled (default true); remainingMinor =
// limit.amount_minor - used.amount_minor; balance formatted with
// limit.exponent decimals (else used.exponent); HasCredits = enabled && remaining > 0;
// Unlimited=false; Enabled=enabled. No spend → Credits nil.
// Plan: the plan argument, else root subscription_type | plan_type | account_type.
// ok=false when no windows.
func Snapshot(root any, observedAt time.Time, origin snapshot.Origin, plan string) (snapshot.Provider, bool)

type LocalSource struct{ MirrorPath string }          // origin local
type LiveSource struct {
    BaseURL     string        // default https://api.anthropic.com
    Client      *http.Client  // default: 15 s timeout
    Credentials func() ([]byte, error)   // default ReadCredentials
}                                                      // origin live
```
LocalSource.Fetch: missing file → NotConfigured("Statusline mirror not
installed — run install-claude-statusline.sh"); root = file JSON; limits =
root["rate_limits"] if present else root; observedAt = root observed_at |
observedAt (jsonx.Time) else file mtime; plan from root subscription_type |
plan; no windows → NoDataFound("Mirror has no usage yet — Claude Code
populates it after its first reply").

LiveSource.Fetch: `GET {BaseURL}/api/oauth/usage` with headers
`Authorization: Bearer <token>`, `anthropic-beta: oauth-2025-04-20`,
`anthropic-version: 2023-06-01`, `Accept: application/json`,
`User-Agent: quotamon/0.1` (honest — no spoofing). 401/403 → Unauthorized
with the "expired" wording when ExpiresAt is in the past, else "rejected";
other non-2xx → `source.ForHTTP`; body → limits = root["rate_limits"] else
root; no windows → Malformed("Unrecognised response from Claude usage
endpoint"). observedAt = now, plan = credentials' Plan.
