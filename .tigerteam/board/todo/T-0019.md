## Goal
The user-friendly first run. `quotamon setup` auto-discovers every provider
quotamon knows how to read, shows the findings, lets the user enable/disable
each and add what discovery could not find (an API key), and writes the
mandatory config file (T-0018). Re-runnable: pre-fills from the existing file.

## Context
- `discover.All()` and `config` from T-0018. Findings include Kimi as
  found-but-unsupported so the user is not left wondering.
- Interaction must be testable: read prompts from an injected `io.Reader`,
  write to an injected `io.Writer`; no TTY tricks, no third-party libs.

## Design — implement exactly this
```
quotamon setup [--yes]
```
Flow (plain text, one screen):
1. Print `Looking for providers…` then a table, one row per finding:
   `✓ Claude      Keychain item present`
   `✓ ChatGPT     ~/.codex/auth.json`
   `✗ Grok        not signed in — run `grok login``
   `✗ DeepInfra   no API key`
   `· Kimi        credentials found, but Kimi exposes no quota API yet`
2. For each **supported** provider, ask `Enable <name>? [Y/n]` — default Y
   when found, n when not found (existing config value wins as the default when
   re-running). For a provider with `NeedsKey` that is enabled and has no key,
   prompt `DeepInfra API key (input hidden is not available; paste and press Enter):`
   — accept empty to skip and leave it disabled.
3. Ask `Add anything else manually? [y/N]` — on y, list the known provider ids
   again and let the user pick one to enable (this exists so a provider that
   discovery missed, e.g. codex on an unusual path, can still be turned on;
   there is nothing to "add" beyond the known set — say so in the prompt:
   `quotamon can read: claude, codex, grok, deepinfra. Enter an id, or blank:`).
4. Write the config; print `Wrote <path> (mode 0600). Run: quotamon`.
`--yes`: no prompts — enable exactly what was found, keys from env only.
Also implement `quotamon providers`: the same table plus an `enabled` column
from the config (no prompts, exit 0; exit 3 with the setup hint when no config).
