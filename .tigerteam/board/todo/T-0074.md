## Goal
T-0073 deletes the `quotactl` executable and the Swift provider layer. Two
places outside that ticket's scope still tell a reader — or a user's shell — to
use them. One is a live instruction that will simply fail.

## Context
- `scripts/install-claude-statusline.sh:48` prints:
  `echo "Open a Claude Code session, then re-run: swift run quotactl"`
  After T-0073 that command errors out. This is the one that actually breaks a
  user, so treat it as the point of the ticket.
- `README.md:260` lists `Sources/quotactl/  diagnostic CLI (the parity
  reference)` in the Layout section, describing a directory that no longer
  exists.
- The replacement for both is the Go binary, `quotamon`. The statusline mirror
  already has a Go path — read `scripts/claude-statusline-mirror.sh` and the
  rest of `install-claude-statusline.sh` before choosing the wording, and make
  the printed command one the user can actually paste and run.
- `GO-PORT.md` mentions `quotactl` several times as a record of how the port was
  verified. That file is a dated historical document: **leave it exactly as it
  is.** A history that edits itself to match the present is worthless.
- `AGENTS.md` also mentions it in four places. That file belongs to the PM —
  do not touch it.
