## Goal
For documentation screenshots we need the exact console table without a real
account (privacy: never ship live percentages/balances). Add `--demo` that
feeds a built-in representative snapshot to the SAME renderer the live table
uses, so the screenshot always matches real formatting.

## Context
- Table renderer + `renderTable`/`renderWaybar` live in `core/cmd/quotamon/`
  (T-0015/T-0021). `snapshot.Snapshot` model in `core/internal/snapshot`.
- No config or network for `--demo` (it must work before setup).

## Design — implement exactly this
- `quotamon --demo` (also honoured by `snapshot --demo`, `waybar --demo`):
  build a fixed `snapshot.Snapshot` in code — Claude (max) 5h/Week/Fable wk at
  a few percents + a `20.00 (not enabled)` credit, ChatGPT (plus) 5h high/Week,
  Grok (nil plan) one Week window, DeepInfra (pay-as-you-go) balance
  `$10.03 remaining` + spend `$8.00 this month`, Kimi (basic) 5h/Week — and
  render it through the normal table/JSON/waybar path. Use a FIXED
  `generatedAt`/`observedAt`/`resetsAt` (relative to a fixed base so countdowns
  are stable, e.g. resets a fixed duration in the future via an injected `now`).
- `--demo` bypasses the config-missing gate and never touches the network,
  the keychain, or a subprocess. Exit 0.
- Colour still obeys `--color`/`NO_COLOR`.

## Acceptance criteria
- [ ] `bash .tigerteam/scripts/run-tests.sh` exits 0
- [ ] Test: `--demo` (via the render function over the built-in snapshot with a fixed `now`) produces a stable, asserted multi-line table containing all five providers, the `(not enabled)` credit, and `$10.03 remaining`
- [ ] Test: `--demo --json` emits valid JSON with 5 providers; `waybar --demo` one line
- [ ] `go run ./cmd/quotamon --demo` exits 0 with no config present
- [ ] `core/README.md` mentions `--demo` (one line, under usage)

## Out of scope
