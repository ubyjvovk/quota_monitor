## Goal
Bring the panel closer to the Mac dropdown's density and identity while staying
inside Omarchy's card idiom (owner's choice, 2026-09-01, over rendering the
console table verbatim). Three changes, each small:

1. **Every provider shows the same icon** — `PanelHero.iconComponent` is a
   hardcoded `Text { text: "󰓅" }`, one speedometer for all. Replace it with the
   provider's badge: `CL`, `GPT`, `GK`, … — the identity the Mac menu bar and
   the Waybar module already use.
2. **Each window costs three lines** — label, bar, then `resets in 3h 34m` on
   its own line. Put the percentage and the countdown on the label line, the
   way the Mac does (`12%  3h 34m`), and drop the third line. Roughly halves
   the height per provider.
3. **Bars only know two colours.** `WindowRow` paints
   `alarming ? root.urgent : root.foreground`, so a window at 85% looks exactly
   like one at 5%. The bar *icon* (`StackedQuotaIcon.qml`) already uses three
   — `normalColor "#879A39"`, `warningColor "#d0772b"`, `criticalColor
   Color.urgent` — and `Model.severity(percent)` already returns
   `normal | warning | critical`. The panel simply never asked.

## Context — read before touching anything
- **Nobody on this board can run the QML.** Follow the T-0067 pattern exactly:
  every *decision* (what text, which severity, which badge) lives in
  `Model.js` behind `model_test.mjs`, and `Panel.qml` only binds to it. The
  reviewer can run node; nobody here can run the panel. The owner will eyeball
  it from plugin `master` on the Omarchy box before it is tagged — keep the
  QML diff small and boring so that eyeball is enough.
- Data shape today: `Model.providerRows(snapshot, nowMs)` yields, per provider,
  `displayName`, `plan`, `windows[]`, credits text, status fields; each window
  has `label`, `percent`, `percentText`, `resetText` (`"resets in 3h 34m"`),
  `alarming`. `Model.providerMeta(row)` builds the `MAX · LIVE · 2M AGO` line.
- The badge map, verbatim from `core/cmd/quotamon/waybar.go` and
  `QuotaKit/.../ProviderSnapshot.swift` `shortNames` (they agree):
  `claude→CL codex→GPT grok→GK deepinfra→DI kimi→KM runinfra→RI openrouter→OR deepseek→DS`.
  Fallback for an unknown id, as the Swift does: the first two characters of
  `displayName`, uppercased.
- Omarchy's `PanelHero` (from `qs.Ui`) takes `title`, `meta`, `iconComponent`.
  Keep using it; only the `iconComponent` changes. Do not restyle the hero.
- The `Style` tokens in use: `Style.space(n)`, `Style.font.{display,body,caption}`,
  `Style.spacing.{sm,controlHeight}`, `root.foreground / dim / urgent / track`.
  Stay within them — no literal pixel sizes, no colours other than the three
  severity colours and the existing `root.*` roles.

## Design (decided; implement exactly this)

**1. `Model.js`**

```js
// The two-to-three-letter identity used by the Mac menu bar and Waybar.
function providerBadge(row)          // row.id → badge; unknown → first two chars of displayName, uppercased; "" if neither

// Just the countdown, for the label line: "3h 34m". "" when there is none.
function countdownText(window, nowMs)
```

- `providerBadge` uses the map above. Add `id` to the row object
  `providerRows` returns if it is not already there.
- `countdownText` is the existing reset countdown **without** the `resets in `
  prefix — derive both from one place so they cannot drift. Keep `resetText`
  exactly as it is; other code and tests use it.
- Each window object gains `severity: severity(percent)` (`"unavailable"` when
  `percent` is null). Keep `alarming` — it is still used for the percentage
  colour.

**2. `Panel.qml`**

- Hero icon: replace the speedometer `Text` with a rounded badge — a
  `Rectangle` with `radius: Style.space(4)`, fill `root.track`, containing a
  `Text` of `Model.providerBadge(modelData)` in `root.foreground`,
  `Style.font.caption`, `font.bold: true`, padded by `Style.space(4)`
  horizontally and `Style.space(2)` vertically. Same footprint as the glyph it
  replaces, so `PanelHero`'s layout does not shift.
- `WindowRow` label line: keep `label` on the left. On the right, **two**
  `Text`s anchored together: the countdown in `root.dim` /
  `Style.font.caption`, then the percentage exactly as today (`percentText`,
  `alarming ? urgent : foreground`), with `Style.spacing.sm` between them.
  Countdown hidden when `Model.countdownText(...)` is `""`.
- **Delete** the trailing `resetText` `Text` block from `WindowRow`.
- `WindowRow` `spacing: Style.space(6)` → `Style.space(4)`; the per-provider
  `Column` `spacing: Style.space(10)` → `Style.space(8)`.
- Bar fill colour becomes a function of `window.severity`, using **the same
  three colours as `StackedQuotaIcon.qml`** so the icon and the panel agree:
  `normal → "#879A39"`, `warning → "#d0772b"`, `critical → root.urgent`,
  anything else → `root.foreground`. Put those three in one small
  `function severityColor(severity)` on the panel root so they are declared
  once. Do not import or instantiate `StackedQuotaIcon` for this.
- Nothing else in `Panel.qml` changes: not the Install/Update/Refresh buttons,
  not the version footer, not the status text, not `installQuotamon`, not the
  watchdogs, not the manifest read.

**3. `omarchy/README.md`**

The paragraph that describes the dropdown ("Click opens a dropdown with
windows, credits, and a Refresh button") gains one sentence: each provider is
labelled with the same two-letter badge the macOS menu bar and Waybar use, and
bars are green / amber / red by the same thresholds as the bar icon.

## Out of scope
- Rendering the console table (the alternative the owner did not choose).
- Brand logos or SVG assets. Badges are text, by design — no trademark
  questions, no assets, and one identity across three surfaces.
- `StackedQuotaIcon.qml`, `BarWidget.qml`, `manifest.json`,
  `fetch-quotamon.sh`, anything under `scripts/` or `core/`.
- Changing `PanelHero`'s styling, the meta line's content or casing, the
  buttons, the footer, or the status/warning texts.
- Any change to `providerMeta`, `creditsText`, `iconBars`, or the reset
  countdown *values* — only where they are shown moves.
