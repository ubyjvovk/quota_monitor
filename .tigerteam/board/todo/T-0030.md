## Goal
The macOS app will stop using the Swift fetchers and instead run the bundled
`quotamon` Go binary and ingest its JSON snapshot (GO-PORT.md cutover step 3).
Add a `QuotamonRunner` to QuotaKit and give `QuotaEngine` a path that refreshes
from it. The Swift providers/sources and their tests STAY (frozen parity
oracle) — do not delete them.

## Context
- `QuotaKit/Sources/QuotaKit/Engine/QuotaEngine.swift` — `@MainActor @Observable`;
  `refresh() async` currently builds `ProviderCatalog.all()` and merges. It also
  owns `store` (SnapshotStore), `history`, and the auto-refresh timer. Reuse all
  of that; only change where the fresh snapshot comes from.
- `QuotaKit/Sources/QuotaKit/Models/QuotaSnapshot.swift` — `decode(from:)` already
  accepts the Go core's JSON (proven by `snapshot-v2.json` in QuotaKitTests).
- AGENTS.md conventions: inject dependencies through the initialiser with a
  working default; anything crossing async is `Sendable`; swift-testing.
- Tests must NOT spawn a real process. Inject the exec seam.

## Design — implement exactly this
```swift
public struct QuotamonRunner: Sendable {
    /// Runs `quotamon` with the given args and returns raw stdout, or throws.
    /// Injected so tests never spawn a process.
    public let run: @Sendable ([String]) async throws -> Data
    public init(run: @escaping @Sendable ([String]) async throws -> Data)

    /// Default runner: executes the binary at `executableURL` via Foundation
    /// `Process`, capturing stdout; maps a non-zero exit to a thrown
    /// `QuotaError` carrying stderr (trimmed). 15s wall cap.
    public static func bundled(executableURL: URL) -> QuotamonRunner

    /// Runs `quotamon snapshot --json` (adds `--fresh` when `fresh`) and decodes
    /// a QuotaSnapshot. Exit code 3 (no config) → throws QuotaError.notConfigured
    /// with an actionable message ("Run first-time setup"). Undecodable → .malformed.
    public func snapshot(fresh: Bool = false) async throws -> QuotaSnapshot
}
```
`QuotaEngine`:
- New initialiser parameter `runner: QuotamonRunner?` (default `nil`). When set,
  `refresh()` calls `runner.snapshot(fresh:)` and uses that snapshot instead of
  the Swift `HybridProvider` path; still persists to `store`, records history,
  updates `lastRefreshedAt`, and clamps concurrency with `isRefreshing`.
- Add `public func refresh(fresh: Bool) async` (the existing `refresh()` calls
  `refresh(fresh: false)`); the force-refresh button will call `refresh(fresh: true)`.
- When `runner == nil`, behaviour is exactly as today (Swift providers) so
  existing tests and previews are unaffected.
- Decode/run errors must not clobber a good prior snapshot: on failure keep the
  last snapshot and surface the error via a new `public private(set) var lastError: String?`
  (nil on success).

## Acceptance criteria
- [ ] `bash .tigerteam/scripts/run-tests.sh` exits 0
- [ ] Test: `QuotamonRunner(run:)` stub returning the bytes of `snapshot-v2.json` → `.snapshot()` yields 2 providers with the expected ids; passing `fresh: true` makes the stub receive an args array containing `--fresh` and `snapshot`
- [ ] Test: stub that throws a non-zero-exit error tagged exit 3 → `.snapshot()` throws `QuotaError.notConfigured`; stub returning garbage → `.malformed`
- [ ] Test: `QuotaEngine(runner:)` with a stub runner → after `refresh()`, `engine.snapshot` equals the stub's providers, `store.load()` returns it, `lastError == nil`; a throwing runner leaves the previous snapshot intact and sets `lastError`
- [ ] Test: `refresh(fresh: true)` propagates `--fresh` to the runner
- [ ] Existing QuotaKit tests still pass unchanged (runner defaults to nil)
