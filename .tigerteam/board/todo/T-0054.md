## Design — implement exactly this
- `QuotamonRunner`: deadline 45 s (doc comment: core budgets 25 s Kimi
  prefetch + 15 s fetch; 45 covers both plus margin). On timeout, kill the
  PROCESS GROUP (spawn with its own pgid), not just the leader. Test: the
  existing timeout test updated; a fake child that ignores SIGTERM is out of
  test scope (document).
- `ConsoleWidgetView.lines` small/medium: a provider with NO current window
  but non-nil credits renders a row: `pad(short,3) + " " + <tableCredits-style
  detail>` (e.g. `DI  $10.03 remaining`), placed after the window rows.
  Staleness: any provider whose origin != live OR status != ok gets ` *`
  appended to its row (fits the width budget; doc comment explains the
  marker); the empty state is unchanged. Update/extend ConsoleWidgetTests.
- `App/SetupView` + `App/QuotamonSetup`: load `quotamon config get --json`
  (T-0048 shape: `api_key_set`, `enabled`) and MERGE saved enabled state with
  discovery — a provider enabled in config starts toggled on even when
  discovery misses it; Save only writes providers whose state changed.
- `App/QuotamonSetup.save`: pass the key via `config set <id> --api-key-stdin`
  writing the key to the child's stdin; never in argv.
