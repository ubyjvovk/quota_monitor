## Goal
The waybar tooltip diverges from the console table it claims to mirror
(findings opus F11, codex F13/F14, ds F4/F9 in
`.tigerteam/reviews/2026-08-31-*.md`).

## Design — implement exactly this
- Tooltip iterates `provider.SortedWindows(now)` (table order).
- Origin rendered via the same mapping as `tableOrigin` (live/cached/
  unavailable) — reuse or mirror it, never the raw string.
- Credit rows via `creditLines(...)` whenever `provider.Credits != nil`
  (drop the `len(Windows)==0` guard); table.go's creditLines is in package
  main — call it directly.
- `Percentage` field clamped to 0..100 (`int(math.Round(min(100, max(0, p))))`);
  Text/tooltip keep the unclamped value.
- Tests: tooltip ordering (session 90 after weekly 40 in payload order →
  session first), origin "cached" for local, credits present with windows,
  percentage 104 → 100.
