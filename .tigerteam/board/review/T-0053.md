## Design — implement exactly this
- `UsageHistory.record`: sample `currentUsedPercent(asOf:)`; when nil (window
  rolled over) SKIP the sample — a gap is the honest series. Keep the
  duplicate-suppression behaviour for real readings.
- `ProviderSnapshot.shortNames`: extend to the full catalog matching
  `core/cmd/quotamon/waybar.go` exactly — grok→GK, deepinfra→DI, kimi→KM
  (claude→CL, codex→GPT unchanged); prefix fallback stays for unknown ids.
  Add a comment naming waybar.go as the source the map must track.
- Tests (swift-testing): rolled-over window produces no new sample; the five
  short names asserted against the Go values.
