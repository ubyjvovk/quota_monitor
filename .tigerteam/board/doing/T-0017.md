## Goal
`hybrid.Provider.Fetch` treats a successful source result as usable only when
`len(Windows) > 0`. DeepInfra (T-0013) is pay-as-you-go: with no spending
limit it has **zero windows by design** and carries its reading in
`Credits.Balance` ("$7.75 this month"). Today that result is discarded and the
provider is reported as `needsSetup: No data source configured` — wrong, and
the PM's spec error, not T-0013's.

## Context
- `core/internal/hybrid/provider.go` (the merge), `core/cmd/quotamon/waybar.go`
  (tooltip), and the table renderer `core/cmd/quotamon/table.go` (T-0015; add
  it and `table_test.go` to scope — see below).
- Credits rules come from Swift `ConsoleReport.creditsLine` (QuotaKit/Sources/QuotaKit/Support/ConsoleReport.swift).

## Design — implement exactly this
- In `core/internal/hybrid/provider.go` define
  `func usable(p snapshot.Provider) bool { return len(p.Windows) > 0 || p.Credits != nil }`
  and use it in both the live-wins and local-fallback checks instead of the
  window-count test. The "every window rolled over" status logic applies only
  when `len(Windows) > 0`.
- In `core/cmd/quotamon/waybar.go` `providerTooltip`: when a provider has no
  windows but has credits, print one line `  <balance>` (or `unlimited`) instead
  of nothing, so DeepInfra shows its spend in the tooltip. Text stays `DI —`.
