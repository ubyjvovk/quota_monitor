## What to hunt (in priority order)
1. Correctness bugs a user would hit: wrong numbers, wrong ordering, wrong
   state after errors, time/reset-boundary handling, nil/empty-payload paths.
2. Credential/secret handling: anything that could log, leak, or mis-scope a
   token or API key; command construction; file modes.
3. Contract drift between surfaces (console table vs macOS panel vs widget vs
   waybar vs omarchy) — the repo's rule is one derived layer, transcribed.
4. Concurrency/lifecycle: the Swift engine's refresh loop, QML process
   handling, cache read/write races.
5. Failure honesty: errors swallowed, staleness presented as live, "0%" where
   "no reading" is meant.
Not wanted: style, naming, formatting, hypothetical perf, TODO archaeology.
