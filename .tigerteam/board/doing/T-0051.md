## Goal
Two defects (opus F8, codex F4 — see the review reports): the overdue-invoice
COUNT renders as `$%d`, and absent/malformed money fields default to zero, so
endpoint drift shows a live `$0.00 this month` instead of "malformed".

## Design — implement exactly this
- Status message: `DeepInfra has %d overdue invoice(s)` (count, no `$`).
- `sources.go`: a months[0] entry WITHOUT a valid `total_cost` float →
  `source.Errorf(source.Malformed, ...)` (same as the missing-months path),
  never a zero spend. Checklist money fields: each absent/malformed component
  degrades that component to unknown (balance omitted), never to $0.00 —
  keep components that did parse.
- Tests: `{"months":[{}]}` → Malformed; checklist without balance fields →
  provider still reports spend but no balance; overdue message text pinned.
