## Goal
Bring the Omarchy plugin's manifest up to the published Omarchy plugin spec and
let the panel say what it is. Four changes to `manifest.json` (namespaced id,
`license`, a `dependencies` declaration, rewritten description text), one new
`LICENSE`, and a footer line in the panel reporting the plugin's own version
next to the version of the `quotamon` binary feeding it — with a visible warning
when that binary is older than the plugin needs.

## Context
- Spec sources (checked 2026-09-01): the Omarchy plugin **develop** guide lists
  `schemaVersion`, `id`, `name`, `version`, `author`, `license`, `description`,
  `kinds`, `entryPoints` as required, with `barWidget` optional; the manual
  states plugin ids are namespaced and that only the `omarchy.*` prefix is
  reserved. **No `dependencies` field is documented** — ours is an
  informational declaration that Omarchy will ignore, which is precisely why
  the panel must enforce it itself. Unknown manifest keys are tolerated (the
  loader validates the required fields, ids, and entry points; it does not
  reject extras).
- `omarchy/manifest.json` already carries `"version": "2026.9.1"` (set by
  T-0065). **Do not change the `version` value.**
- `omarchy/Model.js` is the plugin's derived layer and the only part that is
  testable here — `omarchy/model_test.mjs` runs under node in
  `scripts/test-all.sh`. Nobody on this board can run Hyprland, so the rule
  established in T-0040 stands: **all logic goes in `Model.js` behind node
  tests; `Panel.qml` only renders.** A fourth untested derived layer inside QML
  is the failure mode this ticket must avoid.
- `omarchy/Panel.qml` imports `QtQuick`, `Quickshell`, `Quickshell.Io`,
  `qs.Commons`, `qs.Ui`, and `"Model.js" as Model`. It resolves shipped files
  with `Qt.resolvedUrl(...)` and a `file://`-stripping helper (see
  `installScript`, ~line 34). The panel column ends with a `PanelSeparator`
  followed by the Refresh `Button` (~line 400).
- T-0064 added a top-level `"version"` key to `quotamon`'s snapshot JSON. The
  plugin already parses that JSON on every refresh (`Model.parseSnapshot`), so
  the core's version arrives for free — no second process spawn. A `quotamon`
  older than `2026.9.1` emits **no** `version` key, which is itself the signal
  that it predates the requirement.
- The `id` is also the install directory name
  (`~/.config/omarchy/plugins/<id>/`). Renaming it is a deliberate break the
  owner approved on 2026-09-01; `omarchy/README.md` must teach the new path.
- `omarchy/fetch-quotamon.sh` needs `curl` and `shasum` (it runs
  `shasum -a 256 -c -`), plus coreutils basics.
- The repo has no `LICENSE`; the owner chose MIT (2026-09-01). Copyright
  holder: `ubyjvovk`, year `2026`.

## Design (decided — implement exactly this, do not redesign)

### 1. `LICENSE` (repo root) and `omarchy/LICENSE`
The standard MIT licence text, `Copyright (c) 2026 ubyjvovk`. `omarchy/LICENSE`
is a byte-identical copy — the plugin directory is published standalone by
`scripts/publish-omarchy-plugin.sh` (subtree split), so a licence outside it
never reaches the plugin repo.

### 2. `omarchy/manifest.json`
Change exactly these keys; leave `schemaVersion`, `version`, `kinds`,
`entryPoints`, and the whole `barWidget.schema`/`defaults` blocks alone.

- `"id": "ubyjvovk.quotamon"` (was `"quotamon"`)
- add `"license": "MIT"` immediately after `"author"`
- `"description"`: exactly

  `How much of your LLM subscription quota is left — Claude, ChatGPT, Grok, Kimi, DeepSeek, DeepInfra, OpenRouter and RunInfra — as one stacked bar icon with a click-through panel.`

- add, after `"description"`:

  ```json
  "dependencies": {
    "quotamon": ">=2026.9.1",
    "commands": ["curl", "shasum"]
  }
  ```

  with a note in `omarchy/README.md` that Omarchy does not read this block —
  it is a declaration for humans, and the panel enforces the `quotamon`
  minimum itself.
- `"barWidget"."description"`: exactly

  `Stacked usage bars, one per provider, filled to that provider's tightest quota window and coloured by severity. Click for windows, credits, reset countdowns, and a Refresh button.`

- `"barWidget"."displayName"` and `"category"` stay as they are.

The file must remain valid JSON with the existing 2-space indentation.

### 3. `omarchy/Model.js` — new pure functions (all node-tested)
```
parseManifest(raw)      -> { version: "2026.9.1", minQuotamon: "2026.9.1" }
```
- JSON-parses the manifest text; returns `{ version: "", minQuotamon: "" }` on
  any parse failure or missing key (never throws).
- `minQuotamon` is `dependencies.quotamon` with a leading `>=` stripped and
  trimmed; absent or malformed → `""`.

```
compareVersions(a, b)   -> -1 | 0 | 1 | null
```
- Splits on `.`, compares segment by segment numerically, shorter version
  padded with zeros (`2026.9` < `2026.9.1`).
- Returns `null` when either side is empty or has a non-numeric segment
  (`"dev"`), meaning "cannot tell" — callers must treat `null` as "no warning".

```
coreVersion(snapshot)   -> "2026.9.1" | ""
```
- The snapshot's top-level `version` as a trimmed string; `""` when the
  snapshot is null or the key is missing.

```
aboutText(manifest, snapshot) -> string
```
- With a plugin version and a core version: `Quota Monitor 2026.9.1 · quotamon 2026.9.1`
- Plugin version known, no snapshot yet or no core version:
  `Quota Monitor 2026.9.1 · quotamon version unknown`
- No plugin version (manifest unreadable): `""` — the footer hides entirely.

```
versionWarning(manifest, snapshot) -> string
```
- `""` when there is no snapshot at all (nothing installed yet — the panel
  already shows its Install button; do not double up).
- A snapshot exists but carries no version:
  `quotamon is older than this plugin needs (2026.9.1) — update it and press Refresh`
- A snapshot carries a version older than `minQuotamon`:
  `quotamon 2026.8.3 is older than this plugin needs (2026.9.1) — update it and press Refresh`
- `""` when the core version is equal or newer, or when `compareVersions`
  returns `null`, or when `minQuotamon` is `""`.
- The `2026.9.1` in these strings always comes from the manifest, never from a
  literal in `Model.js`.

### 4. `omarchy/Panel.qml` — rendering only
- Read `manifest.json` once at load. Preferred: a `Quickshell.Io.FileView`
  pointed at the path resolved the same way `installScript` is (`Qt.resolvedUrl`
  + `file://` strip + `decodeURIComponent`). If `FileView` is not available in
  this Quickshell version, an `XMLHttpRequest` against
  `Qt.resolvedUrl("manifest.json")` is an acceptable fallback. Either way the
  raw text goes straight into `Model.parseManifest` and a read failure must
  leave the panel fully functional with an empty footer.
- Below the existing Refresh `Button`, add:
  - a `Text` bound to `Model.versionWarning(...)`, `visible` when non-empty,
    coloured `root.urgent`, `Style.font.caption`, `wrapMode: Text.WordWrap`;
  - a `Text` bound to `Model.aboutText(...)`, `visible` when non-empty,
    coloured `root.dim`, `Style.font.caption`, centre-aligned, wrapping.
- No new process, no new timer, no new setting.

  GitHub repository.
- Restyling the panel, changing the icon, or adding settings.

  an empty footer, never to an error banner.
