## Goal
`quotamon config get --json` encodes the config verbatim, printing api_key in
cleartext (opus F2 — the human path deliberately prints "api key set"); and
the only way to set a key is `--api-key=<value>` in argv, visible via ps
(opus F2, codex F2).

## Design — implement exactly this
- `runConfigGet` `--json`: never emit `api_key`. Emit `"api_key_set": true|false`
  per provider instead (frontends need existence, never the value). Build a
  redacted view struct; do not mutate the loaded config.
- `runConfigSet`: new flag `--api-key-stdin` (mutually exclusive with
  `--api-key`): read the key as the first line of stdin (trim one trailing
  newline; empty → error). `--api-key=` keeps working (documented as visible
  to process listings; point to the new flag).
- Tests: json output contains `api_key_set` and never the key value;
  `--api-key-stdin` round-trips a key into the saved config (0600 already
  enforced by config.Save); both flags together → exit 2.
