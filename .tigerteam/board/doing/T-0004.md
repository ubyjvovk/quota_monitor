## Goal
Every `quotactl` run currently ends the ChatGPT block with:

```
Cached — live refresh failed: ChatGPT usage endpoint returned HTTP 404
```

That line is noise, and it is misleading: it implies a transient outage the user
could wait out. The PM established by hand that it is permanent.

**Findings (PM, 2026-08-29 — do not re-investigate, and do not try to work
around any of it):**
- `https://chatgpt.com/backend-api/api/codex/usage` is the *correct* path — it
  appears verbatim in the Codex CLI binary.
- The host sits behind Cloudflare bot protection. Any plain HTTP client gets
  **403 with an HTML challenge page**; the 404 we surface is that wall, not a
  missing route.
- Codex itself never calls a usage endpoint. It learns limits from **response
  headers** (`x-codex-active-limit`) on real API turns and writes the resulting
  `rate_limits` payload into its session rollout files.
- Therefore `CodexLocalSource` — which reads those rollouts — is not a fallback.
  **It is the only real source of ChatGPT quota**, and it is accurate as of the
  user's last Codex turn.

Make the code say what is true: the local rollout is the source, and a reading
older than its window is a fact about Codex usage, not an error.

## Context
- `CodexLiveSource` is at the bottom of `Providers/CodexSources.swift`. It
  already reads its endpoint from `QUOTA_MONITOR_CODEX_USAGE_URL` with a
  hard-coded default.
- `ProviderCatalog.all` (in `Providers/ProviderCatalog.swift`) builds the
  `HybridProvider` for `codex` and currently passes a live source
  unconditionally.
- `HybridProvider` already handles "local only": pass `live: nil`, or
  `liveEnabled: false`. Read its `fetch()` before changing anything — the
  status-message logic you need is already there.
- A rollout's real payload shape, for reference:
  `{"rate_limits":{"limit_id":"codex","primary":{"used_percent":14.0,
  "window_minutes":300,"resets_at":1788038896},"secondary":{"used_percent":18.0,
  "window_minutes":10080,"resets_at":1788511023},
  "credits":{"has_credits":false,"unlimited":false,"balance":"0"}}}`

## Design — implement exactly this
1. **The live source becomes opt-in.** `CodexLiveSource` stays in the file
   (unchanged in behaviour) but is only wired up when the environment sets
   `QUOTA_MONITOR_CODEX_USAGE_URL`. Add to `Codex`:

   ```swift
   /// The ChatGPT backend sits behind bot protection and refuses plain HTTP
   /// clients, so no live source is wired up unless the user points us at a
   /// reachable endpoint themselves. Quota comes from the session rollouts.
   public static var liveSourceIfConfigured: (any QuotaSource)?
   ```
   It returns a `CodexLiveSource` when `QUOTA_MONITOR_CODEX_USAGE_URL` is set
   and parses as a URL, and `nil` otherwise. `ProviderCatalog.all` passes that
   as the codex provider's `live`.

2. **Say something true when the reading is stale.** `CodexLocalSource` keeps
   returning the newest rollout reading. No change to its parsing. The status
   wording is the fix, and it belongs where `HybridProvider` already sets
   `.needsSetup` for a fully-reset snapshot — but **do not edit
   `QuotaSource.swift`** (out of scope). Instead, `CodexLocalSource.fetch()`
   sets the returned snapshot's `status` itself when every window has reset:

   ```
   ChatGPT reports usage only after a Codex turn — last reading <age> ago
   ```
   using `QuotaFormat.age`. When at least one window still has a live reading,
   leave `status` nil.

3. **Nothing else changes.** Do not delete `CodexLiveSource`, do not touch the
   Claude sources, do not alter the rollout parser.

## Out of scope
- **Trying to reach the ChatGPT backend anyway.** Do not spoof a browser
  User-Agent, do not add cookies, do not attempt to bypass the bot protection.
  This is a deliberate product decision, and the existing comment in
  `ClaudeSources.swift` ("Identifies honestly… nothing to gain by pretending")
  is the standing policy.
- Shelling out to the `codex` binary, or starting `codex app-server`.
- `ClaudeSources.swift`, `Keychain.swift`, `main.swift`, `ConsoleReport.swift`.
- Credits / extra-usage rendering — T-0005 owns that.
