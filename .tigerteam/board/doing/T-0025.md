## Goal
User decisions (2026-08-29): quotamon must **never rotate Kimi's refresh
token itself**, and should **refresh rarely** — a stale token means the Kimi
CLI has not run, so nothing was spent and the last reading is still true
until a window resets. Implement: (1) a per-provider last-reading cache used
whenever the credential is stale-by-timestamp; (2) when even the cache is
too old, refresh by **launching the Kimi CLI itself** for a few seconds
(it rotates and writes its own file on start), then read `/usages` natively.

## Context
- `PROVIDERS.md` § Kimi — endpoint, 15-min token, the "no rotation" policy,
  and why print mode is unusable (`-p ""` refuses; `-p "/usage"` spends).
- Verified recipe (PM, this machine): the TUI needs a pty; `script(1)` gives
  one without tmux. Keystrokes must wait for startup and use `\r`:
  `( sleep 8; printf '/exit\r'; sleep 2 ) | script -q /dev/null kimi`
  → on launch the CLI POSTs `auth.kimi.com/api/oauth/token` when the token
  is expired and rewrites `~/.kimi-code/credentials/kimi-code.json`. Linux
  `script` syntax differs: `script -q -c "kimi" /dev/null`. `/exit` may not
  terminate the process — kill it after a 20 s deadline; that is fine.
- `core/internal/providers/kimi/` (T-0022), `core/internal/hybrid/provider.go`,
  `core/internal/registry/`, `config.Path()` for the cache dir.
- Tests: no real `~/.kimi-code`, no network, no real `kimi`/`script`.

## Design — implement exactly this
### `core/internal/cache`
```go
type Store struct { Dir string }                    // default filepath.Join(filepath.Dir(config.Path()), "cache")
func (s Store) Load(providerID string) (snapshot.Provider, bool)
func (s Store) Save(p snapshot.Provider) error      // <dir>/<id>.json, 0600, temp+rename
```
### hybrid policy — `hybrid.Provider` gains optional fields
`Cache *cache.Store`, `ShortestWindow time.Duration`, `TokenStale func(now time.Time) bool`, `Refresh func(ctx) error`, `Fresh bool`.
Fetch order:
1. If `!Fresh && TokenStale != nil && TokenStale(now)`: load cache; if found,
   `now - ObservedAt < ShortestWindow`, and it still has a current window →
   return it with `Origin: local`, status OK. **No network.**
2. Else if `TokenStale(now)` and `Refresh != nil` → call `Refresh(ctx)`
   (errors become `NeedsSetup("<provider> sign-in is stale — open `kimi` to refresh it (auto-refresh failed: <err>)")` and fall through to local/cached).
3. Proceed as today (live ∥ local). On a usable live result, `Cache.Save`.
Registry wires: `ShortestWindow` 5h (claude, codex, kimi), 7d (grok), 30d
(deepinfra); `TokenStale` from `ParseCredentials(...).ExpiresAt` for kimi
and grok (nil for the rest); `Refresh` only for kimi.
### Kimi refresher (`providers/kimi/refresh.go`)
```go
type CLIRefresher struct { Binary string /*LookPath "kimi"*/; Startup time.Duration /*8s*/; Deadline time.Duration /*20s*/; Store CredentialStore /*to verify*/; Run func(ctx, argv []string, stdin io.Reader) error /*seam; default exec*/ }
func (r CLIRefresher) Refresh(ctx) error
```
Default `Run`: darwin → `script -q /dev/null <kimi>`; linux → `script -q -c <kimi> /dev/null`;
stdin = a reader that sleeps `Startup`, writes `/exit\r`, sleeps 2 s, then EOF;
stdout/stderr discarded; kill at `Deadline`; the run "succeeds" iff the
credential file's `expires_at` is now in the future (re-read after the run) —
the process exit code is irrelevant. `kimi` missing → NotConfigured.
### CLI
`quotamon --fresh` / `snapshot --fresh` / `waybar --fresh` set `Fresh`.
`check` never uses the cache and never triggers Refresh (report token state instead: `Kimi live: token stale (expired 12m ago) — cached reading available`).
