## Goal
DeepInfra currently prints only `spend  $7.97 this month`. The account has a
prepaid balance: `GET /payment/checklist` → `stripe_balance` (negative =
funds ready to spend). Show `balance  $18.00` as the headline and keep the
spend line. Read `PROVIDERS.md` § DeepInfra "Balance" first — including the
PII warning: the response also contains the user's postal address; pick only
the money/status fields.

## Context
- `core/internal/providers/deepinfra/sources.go` (T-0013 + T-0023: two
  parallel calls with per-call timeout — add the third the same way).
- Fixture `deepinfra-checklist.json` (money fields only).
- `snapshot.Credits` today: `HasCredits, Unlimited, Balance, Enabled`. The
  Swift decoder ignores unknown keys, so adding a field is contract-safe.

## Design — implement exactly this
- `snapshot.Credits` gains `Spend *string `json:"spend,omitempty"`` — a
  provider-formatted spend string. Doc comment: "money already spent in the
  current period, when a provider reports it separately from the balance".
- DeepInfra `Fetch` issues **three** GETs concurrently: `/payment/config`,
  `/payment/usage?from=current`, `/payment/checklist`. From checklist take
  ONLY: `stripe_balance`, `recent`, `limit`, `suspended`, `suspend_reason`,
  `overdue_invoices`, `billing_type`, `topup`. Never retain the body.
- Credits mapping:
  - `stripe_balance < 0` → `Balance: "$18.00"` (abs, `%.2f`), `HasCredits: true`, `Unlimited: false`, `Enabled: !suspended`
  - `stripe_balance == 0` → `Balance: "$0.00"`, `HasCredits: false`, `Enabled: !suspended`
  - `stripe_balance > 0` → `Balance: "$X owed"`, `HasCredits: false`
  - checklist failed but usage OK → today's behaviour (`Unlimited: true`, `Balance: "$7.97 this month"`) plus NeedsSetup("Balance unavailable — DeepInfra /payment/checklist: <err>")
  - `Spend`: `"$7.97 this month"` from usage (as today), always when usage succeeded.
  - `suspended` → status `Failed("DeepInfra account suspended: <suspend_reason>")`; `overdue_invoices > 0` → `NeedsSetup("DeepInfra has $X in overdue invoices")`.
- Windows unchanged (only with a positive `limit`).
- Table (`table.go`): when `Credits.Spend != nil` print two rows:
  `  balance   $18.00` (via the normal credits rules — enabled with balance → `$18.00 remaining`) and `  spend     $7.97 this month`. When only `Spend` exists (Unlimited+Balance path), keep the single `spend` row as today.
- Waybar tooltip: same two lines. Text stays `DI —` (no percentage is invented).
