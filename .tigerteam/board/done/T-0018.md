## Goal
Give quotamon a single user-owned config file that every frontend (CLI,
Waybar, Mac app) reads, and a credential-discovery layer the `setup` wizard
(T-0019) will drive. Decisions (user, 2026-08-29): **JSON**, API keys may live
in the file **with mode 0600 enforced**, config is **mandatory** (no file →
tell the user to run `quotamon setup`).

## Context
- Registry today: `core/internal/registry/registry.go` builds every provider
  unconditionally; DeepInfra reads `DEEPINFRA_KEY` from env only.
- Provider credential facts: `PROVIDERS.md` (paths per provider; Kimi has a
  credential file but no quota API — discovery reports it as "found, not
  supported yet"; do NOT call `/me`).
- CLI dispatch: `core/cmd/quotamon/main.go` (after T-0015 there is a bare
  table command, `--json`, `snapshot`, `waybar`, `check`).

## Design — implement exactly this
### `config` package
```go
// Path: $QUOTA_MONITOR_DIR/config.json if set, else $XDG_CONFIG_HOME/quotamon/config.json,
// else ~/.config/quotamon/config.json (all OSes — keep one rule).
func Path() string
type Provider struct {
    Enabled bool   `json:"enabled"`
    Live    string `json:"live,omitempty"`     // codex only: "app-server" (default) | "http" | "off"
    APIKey  string `json:"api_key,omitempty"`  // deepinfra
}
type Config struct { Version int `json:"version"`; Providers map[string]Provider `json:"providers"` }
var ErrMissing = errors.New("no config file")     // → caller prints the setup hint
func Load() (Config, error)   // ErrMissing when absent; refuses (clear error naming the file and `chmod 600`)
                              // when any provider has api_key AND the file mode has group/other bits (skip the mode check on windows)
func (c Config) Save() error  // MkdirAll 0700, write atomically (temp + rename), chmod 0600, sorted keys, 2-space indent
func Default() Config         // version 1, every known provider enabled=false
```
### `discover` package
```go
type Finding struct {
    ID, DisplayName string
    Found     bool
    Supported bool     // false for kimi
    Detail    string   // "Keychain item present", "~/.grok/auth.json (token expires in 4h)", "DEEPINFRA_KEY not set"
    Hint      string   // the one action: "run `claude` and sign in", "run `codex login`", "run `grok login`", "get a key at deepinfra.com/dash/api_keys"
    NeedsKey  bool     // deepinfra
}
// All probes are LOCAL ONLY (files, env, `security` exit code) — no network.
func All() []Finding    // order: claude, codex, grok, deepinfra, kimi
```
Implement each probe in `discover` (do not add methods to the provider
packages): claude → darwin: `security find-generic-password -s "Claude Code-credentials"` (no `-w`, exit code only); else `~/.claude/.credentials.json` exists; codex → `~/.codex/auth.json` exists; grok → `~/.grok/auth.json` has a `https://auth.x.ai::` key (report `expires_at` age if parseable); deepinfra → `DEEPINFRA_KEY` set OR config has api_key; kimi → `~/.kimi-code/credentials/kimi-code.json` exists, `Supported:false`, Hint "no quota API found — see PROVIDERS.md".

### Registry + CLI
- `registry.All(opts)` gains `Config config.Config`: providers with
  `Enabled:false` are omitted; codex `Live` selects app-server/http/off;
  DeepInfra's key comes from config `api_key`, falling back to `DEEPINFRA_KEY`.
  Add `Key func() string` handling in `deepinfra/sources.go` if it is not
  already injectable (it is — keep the field, set it from the registry).
- Every command except `--help`, `setup`, `providers` calls `config.Load()`.
  On `ErrMissing`: bare/`--json`/`snapshot`/`check` print
  `No config yet — run: quotamon setup` to stderr and exit **3**; `waybar`
  prints `{"text":"quota: run setup","tooltip":"Run `quotamon setup` in a terminal","class":"unavailable","percentage":0}` and exits 0.
  A `setup`/`providers` subcommand stub that prints "not implemented" (exit 2) is
  enough here; T-0019 fills them.
