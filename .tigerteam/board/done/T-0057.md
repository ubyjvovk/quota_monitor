## Goal

deleted while wave test suites were being run unsandboxed on the host (PM
review runs bypass Seatbelt). The culprit test was not conclusively

`QUOTA_MONITOR_DIR` is unset or empty, export

remove it on exit via trap. Also export `QUOTA_MONITOR_RENDER=""`? — no, do
NOT touch other vars. A comment records the 2026-08-31 incident in one line
(config deleted by an unsandboxed suite run) — why, not what.
