## Goal
Make `quotamon` useful: run every provider's sources concurrently, merge
live/local per the hybrid rule, and emit the snapshot JSON (`snapshot`), a
Waybar module payload (`waybar`), and per-source diagnostics (`check`).
After this ticket the PM checks that `quotamon snapshot` and `swift run
quotactl --json` agree on every percentage on this Mac.

## Design — implement exactly this
```go
// hybrid
type Provider struct {
    ID, DisplayName string
    Local, Live     source.Source   // either may be nil
    LiveEnabled     bool
    Now             func() time.Time  // default time.Now; tests inject
}
// Fetch runs Live (if enabled) and Local concurrently, then:
//  1. live succeeded with ≥1 window → return it.
//  2. local succeeded with ≥1 window → if NO window has a current reading,
//     status = NeedsSetup("Last reading <age>; its window has since reset");
//     else if live failed, status = NeedsSetup("Cached — live refresh failed: <msg>");
//     return it.
//  3. else Unavailable(id, name, NeedsSetup(most actionable message)) where
//     "most actionable" = highest source.Priority across the failures,
//     local wins ties; none → "No data source configured".
func (p Provider) Fetch(ctx context.Context) snapshot.Provider

// registry
type Options struct{ LiveEnabled func(id string) bool; Env func(string) string }
func All(opts Options) []hybrid.Provider
//   claude: Local=claude.LocalSource{DefaultMirrorPath}, Live=claude.LiveSource{}
//   codex : Local=codex.LocalSource{DefaultHome,16,512KiB}, Live=codex.AppServerSource{}
//           unless Env("QUOTA_MONITOR_CODEX_USAGE_URL") != "" → codex.HTTPSource
// Order is the display order and must be stable.

// cmd/quotamon
//   snapshot [--no-live]      fetch all (10 s overall context), snapshot.Encode → stdout; exit 0 if any
//                              provider has ≥1 window, 1 otherwise
//   waybar   [--no-live]      one-line JSON {"text","tooltip","class","percentage"}:
//                              text as above; tooltip = one line per provider
//                              "Claude · max · live · 2m ago" then "  Fable wk  20%  resets in 1d 20h"
//                              per window (— for no reading) and a status line when not ok;
//                              class = severity of the headline (worst) window ("normal"|"warning"|"critical"),
//                              "unavailable" when nothing has a reading; percentage = headline used percent rounded (0 when none)
//   check    [--no-live]      probe every source individually, print
//                              "<Provider> <live|local>: ok — <n> windows, <plan>" or "… : <kind>: <message>", exit 0
//   --help/-h                 usage; unknown flag/command → usage on stderr, exit 2
```
Add to `core/internal/format`: `Percent(float64) string` ("43%"),
`Countdown(time.Duration) string` mirroring `QuotaFormat.countdown` ("6d
7h", "10h 11m", "42m", "<1m").
