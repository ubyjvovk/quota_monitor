## Goal
Pushing a tag `vX.Y.Z` must produce a GitHub Release carrying
`Quota-Monitor-X.Y.Z-universal.dmg` (the menu-bar app, universal, with the
bundled `quotamon`), the standalone `quotamon-<os>-<arch>` CLI binaries for
Waybar/Linux users, and `SHA256SUMS`. Unsigned (ad-hoc) by default; when the
repo has Developer ID secrets, sign + notarize + staple instead.

## Context
- Build today: `xcodegen generate && xcodebuild -project QuotaMonitor.xcodeproj -scheme QuotaMonitor -configuration Debug …`
  (`scripts/build.sh`). The app target's pre-build script runs `make -C core matrix`
  and `lipo`s `core/bin/quotamon-darwin-arm64` + `-amd64` into
  `Contents/Resources/quotamon` when both exist (`project.yml`) — today `matrix`
  builds no darwin/amd64, so the bundled core is arm64-only.
- Signing defaults live in `Config/Signing.xcconfig` (ad-hoc, `CODE_SIGN_IDENTITY = -`);
  `project.yml` sets `ENABLE_HARDENED_RUNTIME: NO` and `MARKETING_VERSION: 0.1.0`
  — both are overridable on the `xcodebuild` command line.
- No `.github/` exists yet. Sandboxed lanes cannot run `xcodebuild`; you verify
  the pieces that run locally (YAML, Makefile, `package.sh` on a fake app).
- Nobody can test the signed path until the owner has a Developer ID; it is
  best-effort and must not break the unsigned path.

## Design — implement exactly this
### `core/Makefile`
- `matrix` also builds `bin/quotamon-darwin-amd64` (same flags). Keep the
  other three.

### `scripts/package.sh`
`scripts/package.sh <path/to/Quota Monitor.app> <version> <outdir> [--sign "<identity>"]`
- Optional `--sign`: `codesign --force --options runtime --timestamp
  --preserve-metadata=entitlements --sign "<identity>"` on, in order:
  `Contents/Resources/quotamon`, every `Contents/PlugIns/*.appex`, then the
  app bundle. Then `codesign --verify --deep --strict` the app.
- Stage `<outdir>/staging/` with the app and a symlink `Applications -> /Applications`;
  `hdiutil create -volname "Quota Monitor" -srcfolder staging -ov -format UDZO
  "<outdir>/Quota-Monitor-<version>-universal.dmg"`; remove staging.
- Copy `core/bin/quotamon-*` into `<outdir>/`, then write
  `<outdir>/SHA256SUMS` (`shasum -a 256` of every file in outdir, relative names).
- `set -euo pipefail`, usage message on bad args, header comment explaining
  it is what CI runs and can be run by hand.

### `.github/workflows/release.yml`
- `on: push: tags: ['v*']` and `workflow_dispatch`. `permissions: contents: write`.
  One job `release` on `macos-15`.
- Job-level `env`: `VERSION` = tag without `v` (for `workflow_dispatch`:
  `0.0.0-dev`), `HAS_CERT: ${{ secrets.MACOS_CERT_P12 != '' }}`.
- Steps: `actions/checkout@v4`; `actions/setup-go@v5` with
  `go-version-file: core/go.mod`; `brew install xcodegen`;
  `apple-actions/import-codesign-certs@v3` (`if: env.HAS_CERT == 'true'`,
  `p12-file-base64: ${{ secrets.MACOS_CERT_P12 }}`, `p12-password: ${{ secrets.MACOS_CERT_PASSWORD }}`);
  build:
  `xcodegen generate && xcodebuild -project QuotaMonitor.xcodeproj -scheme QuotaMonitor -configuration Release -derivedDataPath build ARCHS="arm64 x86_64" ONLY_ACTIVE_ARCH=NO MARKETING_VERSION="$VERSION" $SIGN_FLAGS build`
  where `SIGN_FLAGS` is empty unsigned, and when `HAS_CERT`:
  `DEVELOPMENT_TEAM="${{ secrets.APPLE_TEAM_ID }}" CODE_SIGN_STYLE=Manual CODE_SIGN_IDENTITY="Developer ID Application" ENABLE_HARDENED_RUNTIME=YES OTHER_CODE_SIGN_FLAGS="--timestamp"`;
  package: `bash scripts/package.sh "build/Build/Products/Release/Quota Monitor.app" "$VERSION" dist` (+ `--sign "Developer ID Application"` when signed);
  notarize (`if: env.HAS_CERT == 'true'`): write `${{ secrets.NOTARY_KEY }}` to a temp `.p8`,
  `xcrun notarytool submit dist/*.dmg --key <p8> --key-id "${{ secrets.NOTARY_KEY_ID }}" --issuer "${{ secrets.NOTARY_ISSUER }}" --wait`,
  `xcrun stapler staple dist/*.dmg`, regenerate `SHA256SUMS`;
  `softprops/action-gh-release@v2` with `files: dist/*`, `generate_release_notes: true`
  (skip on `workflow_dispatch`: upload `dist/` with `actions/upload-artifact@v4` instead).
- A comment block at the top listing the six optional secrets and what each is.

### `README.md`
- New `## Install` section right before `## Quick start`: download the DMG from
  Releases, drag to Applications; unsigned builds → macOS blocks first launch:
  System Settings ▸ Privacy & Security ▸ *Open Anyway*, or
  `xattr -dr com.apple.quarantine "/Applications/Quota Monitor.app"`;
  Linux/Waybar users take `quotamon-linux-<arch>` from the same release.
- In `## Contributing / for agents`: "Releases: `git tag vX.Y.Z && git push origin vX.Y.Z`
  runs `.github/workflows/release.yml`; signing/notarization switch on when the
  secrets listed in the workflow exist."

## Rework (attempt 2)

PM re-ran the sandbox-blocked checks outside Seatbelt on your branch (`2aa74a3`): `package.sh` on a fake app produced the DMG, four binaries and SHA256SUMS, `hdiutil imageinfo` exits 0 — good. You were right about **five** SHA256SUMS lines; the criterion's "six" was the PM's miscount. Four defects remain in the workflow/README; fix all four, nothing else.

1. **Version keeps the `v`.** `VERSION: … github.ref_name …` yields `v0.2.0`, so the DMG is `Quota-Monitor-v0.2.0-universal.dmg` and `MARKETING_VERSION=v0.2.0`. The ticket says the tag *without* `v`. Replace the job-level `VERSION` env with a first step that computes it in shell and exports it: `case "$GITHUB_REF" in refs/tags/v*) echo "VERSION=${GITHUB_REF_NAME#v}" >> "$GITHUB_ENV" ;; *) echo "VERSION=0.0.0-dev" >> "$GITHUB_ENV" ;; esac`.

2. **Quoted flags built with `format()` break word-splitting.** `SIGN_FLAGS` and `SIGN_CMD` contain literal double quotes; expanding `$SIGN_FLAGS` unquoted in `run:` passes `CODE_SIGN_IDENTITY="Developer`, `ID`, `Application"` as three arguments to `xcodebuild`, and `package.sh` receives `"Developer` as the identity. Drop both `format()` envs. In the build step's `run:` build a bash array: `flags=(); if [ "$HAS_CERT" = "true" ]; then flags+=(DEVELOPMENT_TEAM="$APPLE_TEAM_ID" CODE_SIGN_STYLE=Manual CODE_SIGN_IDENTITY="Developer ID Application" ENABLE_HARDENED_RUNTIME=YES OTHER_CODE_SIGN_FLAGS=--timestamp); fi` and pass `"${flags[@]}"` (with `APPLE_TEAM_ID: ${{ secrets.APPLE_TEAM_ID }}` as a step env). In the package step: `if [ "$HAS_CERT" = "true" ]; then bash scripts/package.sh "$APP" "$VERSION" dist --sign "Developer ID Application"; else bash scripts/package.sh "$APP" "$VERSION" dist; fi`.

3. **Notary key is documented as base64 but written raw.** `echo "${{ secrets.NOTARY_KEY }}" > notary.p8` → make it `printf '%s' "$NOTARY_KEY" | base64 --decode > notary.p8` with `NOTARY_KEY: ${{ secrets.NOTARY_KEY }}` in the step's `env:` (never interpolate secrets straight into the script body — same for `NOTARY_KEY_ID`/`NOTARY_ISSUER`; use env vars).

4. **README links to a made-up repo** (`https://github.com/quotamonitor/quota-monitor/releases`). The real remote is `github.com/ubyjvovk/quota_monitor`; use `https://github.com/ubyjvovk/quota_monitor/releases`.
