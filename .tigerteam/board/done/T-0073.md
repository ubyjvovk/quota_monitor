## Goal
The Go core owns quota fetching. The Swift fetchers under
`QuotaKit/Sources/QuotaKit/Providers/` and the `quotactl` diagnostic CLI were
the port's reference semantics and parity oracle; the port is finished, so they
are now a second, unreachable implementation of the same behaviour that every
future provider change would have to be kept honest against. The owner has
asked for them gone.

They are **already dead at runtime** — this ticket removes code the shipping
app cannot reach, it does not change behaviour.

## Context — the PM's survey (do not re-derive)

- `QuotaEngine.refresh(fresh:)` returns early whenever `runner` is non-nil:

```swift
if let runner {
    do { let freshSnapshot = try await runner.snapshot(fresh: fresh); accept(freshSnapshot); lastError = nil }
    catch { lastError = error.localizedDescription }
    return
}
let providers = makeProviders()   // <- everything below here is unreachable in the app
```

- The only real engine in the app is `QuotaEngine(runner: CoreBinary.runner)`
  (`App/QuotaMonitorApp.swift:10`), so the runner is always present. The other
  construction site is `QuotaEngine(preview:)` (`App/DesignSnapshot.swift:38`),
  which sets `runner = nil` and exists for SwiftUI previews and design
  rendering — it never refreshes.
- A symbol-by-symbol reference scan across `QuotaKit/Sources`, `App/`,
  `Widget/` and `QuotaKit/Tests` shows the whole `Providers/` layer
  (`ClaudeLiveSource`, `ClaudeLocalSource`, `CodexLiveSource`,
  `CodexLocalSource`, `ProviderCatalog`, `HybridProvider`, `QuotaSource`,
  `QuotaError`) is referenced **only** by the library itself, its own tests,
  and `quotactl`. Neither `App/` nor `Widget/` touches any of it. The `Claude`

  references — check them yourself before believing me.
- Cascade once `Providers/` and `quotactl` go:
  - `Support/ConsoleReport.swift` — referenced only by the tests and `quotactl`.
  - `Support/Keychain.swift` — referenced only by `Providers/`,

  - `Support/JSONValue.swift` — referenced only by `Providers/`.
- `UI/PreviewData.swift` uses `Claude.providerID` and `Codex.providerID`, which

  the provider suite. `ConsoleTableTests` (7), `ConsoleWidgetTests` (8) and

## Answers

Good stop — you were right to hand off rather than guess, and the three symbols
you named are exactly the gaps in my survey. My scan classified files by where a
type is *declared*, so `QuotaError` got swept in with the provider layer it
happens to live in. It is not dead. Here is the resolution; the scope is
amended to include the three extra paths named below.

## 1. `QuotaError` is live — move it, don't delete it

It is the error currency of `Engine/QuotamonRunner.swift`, which survives and is
the app's only path to the Go core. Create
**`QuotaKit/Sources/QuotaKit/Support/QuotaError.swift`** and move the enum there
before deleting `Providers/QuotaSource.swift`.

Move **verbatim**: the `public enum QuotaError: LocalizedError, Sendable`
declaration, its five cases, and `errorDescription`.

**Keep `errorDescription` even though nothing names it.** It is the
`LocalizedError` conformance, and it is load-bearing: `QuotaEngine.refresh`
reports failures as `lastError = error.localizedDescription`, which routes
through it. Delete it and every error the panel shows silently degrades to a
generic system string. This is the one member that looks unreferenced and is not.

**Drop these three**, which I verified have zero references across
`QuotaKit/Sources`, `QuotaKit/Tests`, `App` and `Widget` on your branch:

- `var isTransient`
- `var reportingPriority`
- the whole `public extension QuotaError { static func forHTTP(...) }`

They existed to serve the provider layer's HTTP handling, which is going. List
what you dropped in the report.

## 2. `Claude.providerID` / `Codex.providerID` in two surviving files

Same treatment you already applied in `PreviewData.swift` — replace the constant
with the literal the Go core emits. Both are in scope now:

- **`QuotaKit/Sources/QuotaKit/Engine/SnapshotStore.swift:52`**
  `[Claude.providerID: true, Codex.providerID: true]` → `["claude": true, "codex": true]`
- **`QuotaKit/Sources/QuotaKit/Models/ProviderSnapshot.swift:235-236`**
  `Claude.providerID: "CL"` → `"claude": "CL"`, and
  `Codex.providerID: "GPT"` → `"codex": "GPT"`

Change nothing else in either file. The remaining `Claude`/`Codex` hits in those
files and in `QuotaWindow.swift` are prose in comments and display strings —
leave every one of them exactly as written.

## Amended scope

Add to the ticket's scope, in addition to everything already listed:

- `QuotaKit/Sources/QuotaKit/Support/QuotaError.swift` (new)
- `QuotaKit/Sources/QuotaKit/Engine/SnapshotStore.swift`

Everything else in the ticket stands unchanged — in particular `App/` and

`QuotamonRunnerTests.swift` must remain unmodified and green.
