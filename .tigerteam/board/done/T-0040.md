## Goal
PR #1 adds `omarchy/` — a Quickshell/Omarchy bar plugin rendering `quotamon
--json` (stacked-bar icon + dropdown). A PM code review found 15 defects. Fix
them all on this branch. Two themes: the process-spawning layer is fragile and
injectable, and `Model.js` re-implements the derived layer (ordering, credits,
countdown/age, thresholds) differently from every other surface. The repo's
contract is "everything above the snapshot is a dumb renderer" — where
derivation is unavoidable, it must be transcribed from the Go reference and
pinned by a runnable test.

## Design — implement exactly this

### A. Process layer (`Panel.qml`)
1. **No shell.** Delete `fetchCommand()`. `refreshNow(fresh)` sets
   `fetchProc.command = fresh ? [root.binary, "--json", "--fresh"] : [root.binary, "--json"]`
   (argv array — never a concatenated string, never `bash -lc`). `binary` =
   `String(setting("exec", "quotamon")).trim()`, and when it is empty fall
   back to `"quotamon"`. Document in `omarchy/README.md`: set `exec` to an
   absolute path when `quotamon` is not on the shell's PATH.
2. **Exit-code-driven handling.** The two `StdioCollector`s only buffer
   (`property string stdoutBuf/stderrBuf` on the Process or panel; collectors
   assign in `onStreamFinished`). All interpretation moves to
   `onExited: function(exitCode, exitStatus)`: `refreshing = false`; if
   `exitCode === 0` → `applyOutput(stdoutBuf)` (on parse failure set
   `lastError = "unparseable quotamon output: " + first 200 chars`); else
   `lastError = stderrBuf.trim() || ("quotamon exited " + exitCode)`. Then the
   existing `pendingFresh` logic — but only requeue when the just-finished
   fetch was NOT itself fresh (track `property bool currentFresh`).
3. **Interval hardening.** `refreshIntervalSec`: parse with `Number`, and
   `isFinite(v) ? Math.min(3600, Math.max(30, Math.round(v))) : 300`.
4. **No fetch storms.** Remove `triggeredOnStart: true` from the refresh
   Timer. Initial fetch = a one-shot `Timer { interval: 1000; running: true; onTriggered: root.refreshNow(false) }`
   (fires after the host has injected settings).
5. **Visible staleness.** Add an error banner `Text` at the TOP of `column`,
   `visible: root.lastError !== ""` (regardless of rows), colour `root.urgent`,
   `wrapMode: Text.WordWrap`, text `root.lastError` — so a broken fetch is
   visible even while stale rows keep rendering. Keep the existing empty-state
   fallback for the no-rows case (drop its lastError branch — the banner owns
   errors now).

### B. Panel lifecycle (`Panel.qml`, `BarWidget.qml`)
6. `onOpenedChanged`: add the `else` branch — when `!opened`, call
   `setCenterHoverRevealSuppressed(false)` (fixes the leak when the popout is
   dismissed without `close()`).
7. `BarWidget.closeForPopoutSwitch()`: guard like its siblings —
   `if (panelLoader.item && typeof panelLoader.item.closeForPopoutSwitch === "function")`.
8. Dead code: delete the unreachable `open()` (keep `openFromHotkey`; the
   IpcHandler's `open` keeps calling `openFromHotkey`), the write-only
   `openedFromHotkey` property, and the unused `label` property.
9. Scroll preservation: when `rows` changes while the panel is open, restore
   `panelFlick.contentY` (capture in a `onRowsChanged`/`Qt.callLater` pair,
   clamped to the new contentHeight) so the 30 s tick stops snapping the view
   to the top.
10. Credits `Text` in the delegate: add `wrapMode: Text.WordWrap`.

### C. Model parity (`Model.js`) — transcribe, don't invent
11. `formatCountdown`: bands identical to Go `format.Countdown` with the
    `"resets in "` prefix: `Xd Yh` / `Xh Ym` / `Xm` / `<1m` (remaining <= 0 →
    `"window reset"`; missing/invalid resetsAt → `""`). Kill `Math.max(1, minutes)`.
12. `formatAge`: identical to Go `format.Age`: `<5s` → `just now`, `<60s` →
    `Ns ago`, then `Nm ago` / `Nh ago` / `Nd ago`.
13. `sortedWindows(provider, nowMs)` (new): transcription of Go
    `SortedWindows` — current-reading windows first, higher percent first,
    ties and no-reading tail by `kindRank` (session 0, weekly 1, monthly 2,
    else 3; `window.kind` in the JSON). `providerRows` uses it.
14. `tightestForRow`/`tightestPercent`: apply `TightestWindow`'s tie-break
    (percent, then kindRank) — return the window, not just the percent, where
    needed; guard null elements in both (the existing `tightestPercent` crashes
    on a null window entry).
15. `creditsText`: transcription of `creditLines` + `tableCredits`, labels
    included, joined with `" · "`: spend + !unlimited → `"balance <detail>"`
    (omitted when tableCredits omits) + `"spend <spend>"`; else single part —
    unlimited+balance → `"spend <balance>"`, unlimited → `"credits unlimited"`,
    enabled → `"credits <balance||—> remaining"`, disabled →
    `"credits <balance> (not enabled)"` only when balance is non-empty/non-zero
    after trimming currency symbols and whitespace (`,`→`.` before parsing).
16. `iconBars`: DELETE the sort — snapshot order, exactly like the panel rows
    and the macOS icon (`App/MenuBarIcon.swift`, T-0036). Fix the comment.
17. `providerMeta`/`providerRows`: map origin like `tableOrigin` — `live`,
    `local`→`cached`, anything else → `unavailable`; and when origin is
    unavailable drop the age part (Go prints age for every origin — but the
    macOS panel omits it for unavailable; follow the GO table: keep age
    always. Just fix the label mapping.)
18. `alarming`: derive from `severity(percent) === "critical"` — one threshold
    definition only.

### D. Tests — `omarchy/model_test.mjs` (new)
- Plain Node ESM, no deps: read `Model.js` with `fs`, `eval` it in a scope (or
  `new Function`), then assert with `node:assert`. Cases, at minimum:
  countdown bands (40h → `resets in 1d 16h`, 59s → `resets in <1m`, past →
  `window reset`, null → `""`); age bands (3s → `just now`, 45s → `45s ago`);
  sortedWindows order + kindRank tie-break (two windows same percent: session
  first); tightest tie-break; iconBars preserves snapshot order; creditsText:
  demo Claude (`credits 20.00 (not enabled)`), demo DeepInfra
  (`balance $10.03 remaining · spend $8.00 this month`), unlimited spend-only
  (`spend $7.75 this month`), unlimited no balance (`credits unlimited`),
  disabled `$0.00` → `""`; parseSnapshot rejects garbage; tightestPercent with
  a null window element does not throw. Load
  `QuotaKit/Tests/QuotaKitTests/Fixtures/quotamon-demo.json` for the demo cases.
- Wire into `scripts/test-all.sh` behind a guard:
  `if command -v node >/dev/null 2>&1; then echo "### node (omarchy model)"; node omarchy/model_test.mjs || rc=1; fi`.

### E. Docs
19. `omarchy/README.md`: install snippet must start from a checkout —
    `git clone … && cd quota_monitor` then `cp -a omarchy/. ~/.config/omarchy/plugins/quotamon/`
    (never `cp -a .` from an ambiguous cwd). Root `README.md` snippet already
    uses `cp -a omarchy/.` — align wording. Fix the icon-parity sentence in
    both: bars are in the panel's own order (top bar = first row), matching
    the macOS glyph. Document the `exec` absolute-path note (A1) and the known
    limitation that on per-monitor bars each bar instance fetches
    independently.
