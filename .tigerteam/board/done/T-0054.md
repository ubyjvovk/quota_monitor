### Files changed
- `QuotaKit/Sources/QuotaKit/Engine/QuotamonRunner.swift` — deadline 15 s → 45 s
  (`public static let timeout`, doc comment records the 25 s Kimi pre-fetch +
  15 s fetch budgets). `Process` replaced with `posix_spawn` +
  `POSIX_SPAWN_SETPGROUP`/`posix_spawnattr_setpgroup(…, 0)` so the child is its
  own group leader and the timeout path can `kill(-pid, SIGTERM)` then
  `kill(-pid, SIGKILL)` the whole group — the core launches vendor CLIs, and

### For the reviewer
1. **`ConsoleTable.tableCredits` is duplicated.** `creditsDetail` /
   `isEmptyOrZero` in `ConsoleWidgetView` are a transcription of the private
   `tableCredits` / `disabledCreditBalanceIsEmptyOrZero` in
   `QuotaKit/Sources/QuotaKit/Support/ConsoleTable.swift`. Sharing them needs
   only `private static func tableCredits` → `static func tableCredits`
   (same module, no behaviour change, golden test unaffected), but
   `ConsoleTable.swift` is outside this ticket's scope so I did not touch it.
   Worth a one-line follow-up — this is exactly the "third derived layer that
   drifts" pattern the PR #1 review flagged.
2. **The pgid group-kill is not unit-tested.** A fake child that ignores
   SIGTERM is out of test scope per the design, so `terminateGroup` has no
   coverage; the spawn/argv/stdin/stdout/exit paths around it do
   (`bundledRunnerFeedsStandardInputAndCapturesStandardOutput`,
   `bundledRunnerReportsANonZeroExitWithItsStandardError`). Those two tests do
   spawn a real process (`/bin/cat`, `/bin/sh`) — no network, Keychain or
   `$HOME` — which is new for this suite; they pass under the worker sandbox.
3. **Width budget.** A stale small row is 19 cells, not 17, and the credits row
   is 20 (`DI  $10.03 remaining`); `minimumScaleFactor(0.7)` absorbs it. The
   design chose the marker over the width, and the enum doc says so. Worth an
   eye at render time.
4. **Merge rule for saved state.** `saved wins over discovery` rather than an
   OR: OR-merging would re-enable a provider the user had deliberately switched
   off. `config get --json` merges defaults over the file, so it always lists
   all five providers and cannot itself say "never configured" — the
   missing-file check in `savedProviders()` is what draws that line. If the
   config read fails, `load()` surfaces the error and renders no rows rather
   than silently falling back to discovery defaults (which is what would
   re-introduce the silent-disable bug).
5. **`QuotamonRunner.timeout` is public.** Needed only by the test, but a public
   `bundled` doc comment links to it; happy to make it internal if you'd rather
   keep the surface narrow.
6. `xcodebuild` + `QUOTA_MONITOR_RENDER` not run — the opus lane's allowlist
   blocks it, as the ticket says. Panel/widget render and the setup flow are
   yours to verify.
