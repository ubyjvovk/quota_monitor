## Goal
T-0064 through T-0067 changed how this project is versioned and what each
component reports. `README.md` still documents the old scheme and the old

## Context

What landed:
- `VERSION` at the repo root is the single source of truth. The scheme is
  CalVer `YYYY.M.MICRO`: 4-digit year, unpadded month, and the release count
  within that month starting at 1 (`2026.9.1`, `2026.9.2`, `2026.10.1`).
  MICRO is not the day of the month. Current value: `2026.9.1`.
- `scripts/set-version.sh <calver>` is the only supported way to bump it; it
  writes `VERSION`, `project.yml`'s `MARKETING_VERSION`, and
  `omarchy/manifest.json`'s `version` together.
- `scripts/check-versions.sh` fails the test suite when those drift; it runs
  as part of `scripts/test-all.sh`.
- `scripts/release.sh` now tags `v$(cat VERSION)` instead of computing
  `{major}.{commit count}`, and `--next` prints the suggested next CalVer.
- The Go core is stamped at link time from `VERSION`; `quotamon --version`
  prints `quotamon 2026.9.1`, and the snapshot JSON carries a top-level
  `version` key.
- The macOS About panel shows the app version plus the bundled core's version.
- The Omarchy plugin id is now `ubyjvovk.quotamon`, so it installs to
  `~/.config/omarchy/plugins/ubyjvovk.quotamon/`; its panel footer reports the
  plugin version and the quotamon version, and warns when the installed
  quotamon is older than the manifest's declared minimum.
- The repo now has an MIT `LICENSE`.

Sections of `README.md` that are stale or affected:
- **"Contributing / for agents" → the `Releases:` bullet** (~line 287) still
  describes `{major}.{commit count}` and `0.264`.
- **"Omarchy / Waybar" → "Developing the plugin"** (~line 137) uses
  `~/.config/omarchy/plugins/quotamon` in three commands, including
  `omarchy plugin enable quotamon --section center --after omarchy.clock`.
- Wherever the snapshot JSON's shape is described, the new `version` key
  belongs there.
- Line ~27 links to `core/README.md`, **which does not exist**. Fix the link
  (point at `core/` or drop the link) — do not create that file.
