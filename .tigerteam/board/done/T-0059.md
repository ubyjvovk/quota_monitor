## Goal
`scripts/release.sh` (T-0058) refuses to run on the owner's real repo because
`git status --porcelain` counts UNTRACKED files as dirty, and this repo
routinely carries untracked scratch files (`.tigerteam/STOP.*`, personal
notes). The board's own convention is "untracked files are fine"; the guard
must protect against uncommitted TRACKED changes only.

## Design — implement exactly this
Both cleanliness checks (the `--dry-run` one and the real one) use
`git status --porcelain --untracked-files=no`; error message becomes
"uncommitted tracked changes present; commit or stash before cutting a
release". Nothing else changes.
