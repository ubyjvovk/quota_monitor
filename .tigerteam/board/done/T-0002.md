## Goal
`quotactl` today is a *diagnostic* that probes each source separately and prints
one block per source. What the project actually needs first is a **console
version of the app**: run it, get every configured provider's resolved quota,
one line per window. The macOS menu-bar app and widget are on hold, so this
console output is the primary interface for now and must stand on its own.

## Context
- `HybridProvider.fetch()` (in `Providers/QuotaSource.swift`) already does the
  resolution — live wins, local is the labelled fallback, failures become a
  `ProviderSnapshot.unavailable` carrying an actionable status. Use it. Do not
  re-implement source selection in the CLI.
- The provider list is currently built by the private `@MainActor`
  `QuotaEngine.makeProviders()` in `Engine/QuotaEngine.swift`. The CLI cannot
  reach it. Extract it (below) so engine and CLI share one list — a provider
  added later must appear in both without a second edit.
- `ProviderSnapshot` gives you `sortedWindows()`, `age()`, `plan`, `status`,
  `credits`; `QuotaWindow` gives `label`, `currentUsedPercent()`,
  `timeUntilReset()`. `Support/QuotaFormat.swift` already formats ages.
- Existing `main.swift` has local helpers `padded(_:)` and
  `Self_formatDuration(_:)`; the duration one duplicates what `QuotaFormat`
  should own. Move duration formatting into `QuotaFormat` if it is not there,
  rather than keeping a copy in `main.swift`.

## Design — implement exactly this
```swift
// Providers/ProviderCatalog.swift  (new)
/// The single source of truth for which providers exist and in what order.
public enum ProviderCatalog {
    /// - Parameter isLiveEnabled: per-provider-id switch; default enables all.
    public static func all(
        isLiveEnabled: (String) -> Bool = { _ in true }
    ) -> [HybridProvider]
}

// Support/ConsoleReport.swift  (new)
/// Renders resolved snapshots as plain text. A pure function of its inputs —
/// no I/O — so it is unit-testable without network or Keychain.
public enum ConsoleReport {
    public static func render(_ snapshots: [ProviderSnapshot], asOf: Date) -> String
    public static func renderJSON(_ snapshots: [ProviderSnapshot], asOf: Date) throws -> String
}
```
`QuotaEngine.makeProviders()` becomes a call to `ProviderCatalog.all` passing
`settings.isLiveEnabled`. Its behaviour must not change.

`render` output — one provider block each, windows in `sortedWindows()` order:

```
Claude          max                                    live · 2s ago
  5h              10.0%  resets in 2h 39m
  Week            14.0%  resets in 1d 21h

ChatGPT         plus                                cached · 15d ago
  Week                —  no reading since this window reset
  credits          0 remaining

Gemini                                                     unavailable
  Not signed in — run `gemini` to sign in
```

Rules:
- A window whose `currentUsedPercent()` is `nil` renders `—`, **never `0.0%`**
  (AGENTS.md gotcha 5).
- A missing plan renders as empty, not `nil` or `—`.
- The right-hand tag is `live`/`cached`/`unavailable` from the snapshot's
  `origin` and `status`, plus the reading's age.
- A provider with a `status` message prints that message indented under it.
- Output is plain ASCII, no colour, no box drawing. It must be readable when
  piped to a file.
- `renderJSON` emits an object keyed by provider id, with `plan`, `origin`,
  `observed_at` (ISO-8601), `status`, and a `windows` array of
  `{id, label, used_percent (null when no reading), resets_at}`. Use
  `JSONEncoder` with `.sortedKeys` and `.prettyPrinted` so output is stable.

`main.swift` argument surface — exactly these, and a `--help` listing them:
| flag | behaviour |
|---|---|
| *(none)* | resolved quotas for every provider via `ProviderCatalog.all` + `HybridProvider.fetch()`, rendered by `ConsoleReport.render` |
| `--json` | same data via `renderJSON` |
| `--no-live` | as above but local sources only (`isLiveEnabled` returns false) |
| `--diagnose` | today's per-source output, moved behind this flag unchanged |
| `--debug-auth` | unchanged, still additive |
| `--help`, `-h` | usage text, exit 0 |

Exit code: `0` if at least one provider produced a window; `1` if none did (so
the tool is usable from a shell conditional). `--help` always exits 0.
An unrecognised flag prints usage to stderr and exits `2`.

  illustration of the unavailable layout).
