## Goal
Add RunInfra (runinfra.ai) as the sixth provider. PM probed the endpoint live
today (HTTP 200): `GET https://api.runinfra.ai/v1/credits`,
`Authorization: Bearer <key>`. It reports prepaid credits + period spend +an
optional monthly spend cap. Live-only (no local file source). Mirror the
DeepInfra provider end-to-end — read its package, registry entry, discover
probe, and setup flow FIRST and copy the structure.

## Endpoint contract (PM-verified against a real account; all money in US CENTS, integers)
```json
{"object":"credits","balance_cents":2560,"held_cents":60,"available_cents":2500,
 "currency":"usd","period":{"start":"2026-08-01T00:00:00.000Z","spent_cents":785},
 "spend_cap":{"limit_cents":5000,"hard":true,"used_cents":785,
  "remaining_cents":4215,"gates_inference":false},
 "plan_tier":"pro","as_of":"2026-08-31T19:48:55.384Z"}
```
- `spend_cap.*` fields are null when no cap is set; `hard:false` = alert-only.
- Timestamps carry FRACTIONAL seconds + Z — the parser must accept them
  (our own emitted JSON stays fractional-free per the contract).
- Rate limit: 60 reads/min per key. 401/403 = bad key; 429 = rate limited.

## Design — implement exactly this
- Package `core/internal/providers/runinfra/` (+ its README.md): `Snapshot`
  pure function + a live source behind an injected `*http.Client` with
  working default (AGENTS.md conventions; tests use `httptest`, never network).
- Mapping to `snapshot.Provider`:
  - ID `runinfra`, DisplayName `RunInfra`, Plan = `plan_tier` (nil when empty).
  - Credits: Balance = `available_cents` as `$X.XX` (available is what
    admission checks — never the ledger `balance_cents`), Spend =
    `period.spent_cents` as `$X.XX this month`, Enabled true, Unlimited
    false, HasCredits = available > 0. `held_cents` ignored (transient).
  - Window ONLY when `spend_cap.limit_cents` non-null AND `hard` true:
    label `Cap`, monthly kind, usedPercent = used/limit*100, ResetsAt nil
    (the API gives no period end), windowMinutes per the monthly convention
    DeepInfra uses. A soft or absent cap yields NO window — comment why:
    `gates_inference` is false, a soft cap is advisory and must not read as
    quota pressure.
  - ObservedAt = `as_of` (fallback: now). Missing/malformed `available_cents`
    or `period.spent_cents` → `source.Malformed` (never $0.00 — T-0051 rule).
  - 401/403 → NeedsSetup(`RunInfra API key rejected — set RUNINFRA_TOKEN or run: quotamon config set runinfra --api-key-stdin`);
    429 → Transport rate-limited message; other non-200 → Transport.
- Registry: entry after kimi; key from config `api_key`, with the same
  env-var fallback/discovery DeepInfra has for `DEEPINFRA_KEY`, using
  **`RUNINFRA_TOKEN`**. No TokenStale/Refresh (plain API key). Cache wired
  like DeepInfra.
- Discover: probe = `RUNINFRA_TOKEN` set (or config key present); supported,
  needsKey — mirror DeepInfra's finding fields so SetupView renders it.
- Waybar short name `RI` (waybar.go map + test); Swift
  `ProviderSnapshot.shortNames` gains `"runinfra": "RI"` (the map's comment
  says it must track waybar.go) + extend the existing short-name test.
- Fixture `QuotaKit/Tests/QuotaKitTests/Fixtures/runinfra-credits.json`:
  EXACTLY the JSON block above (sanitised numbers, real shape). Go tests load
  it via `internal/fixtures` like the other providers; also test the null-cap
  variant inline, the soft-cap (hard:false ⇒ no window) case, 401, 429, and
  malformed-money cases. Table-driven, `t.Run` names as sentences.
- Docs: PROVIDERS.md gets a RunInfra section (endpoint, Bearer auth, cents
  units, fractional timestamps, 60/min limit, cap semantics incl.
  gates_inference); core/README.md provider list mentions RunInfra; provider
  package README.md.
