## Goal
Port ChatGPT/Codex quota reading to the Go core with three sources:
**live via `codex app-server --stdio`** (preferred, no token handling),
**local via the newest session rollout's tail**, and an **optional HTTP
source** enabled only by `QUOTA_MONITOR_CODEX_USAGE_URL`. One parser serves
all three, because the payloads differ only in key spelling.

  traps) and § cross-cutting rules; `GO-PORT.md`.
- Swift reference: `QuotaKit/Sources/QuotaKit/Providers/CodexSources.swift`
  (parser + rollout tail reader) and the app-server design in

- Tests must never spawn `codex`, hit the network, or read `$HOME` — inject.

## Design — implement exactly this
Package `core/internal/providers/codex`:
```go
const ProviderID = "codex"; const DisplayName = "ChatGPT"
func DefaultHome() string   // ~/.codex

// Window parses {used_percent|usedPercent, window_minutes|windowDurationMins|windowMinutes,
// resets_at|resetsAt} from ONE node (explicit keys on that node, no recursion).
// Label/Kind come from snapshot.LabelFromMinutes / KindFromMinutes — never assume primary == 5h.
func Window(node any, id string) (snapshot.Window, bool)

// Snapshot: windows from limits["primary"] then ["secondary"] (skip nulls);
// credits from limits["credits"]: HasCredits = has_credits|hasCredits (default false),
// Unlimited = unlimited, Balance = balance (string), Enabled = HasCredits || Unlimited;
// plan = plan_type|planType. ok=false with no windows.
func Snapshot(limits any, observedAt time.Time, origin snapshot.Origin) (snapshot.Provider, bool)

// --- live: app-server -------------------------------------------------
type AppServerSource struct {
    // Run executes the exchange and returns raw stdout. Default: exec
    // `codex app-server --stdio` (LookPath "codex"), write the three lines,
    // CLOSE STDIN, read stdout to EOF, 10 s context timeout, kill on timeout.
    Run func(ctx context.Context, requests []byte) ([]byte, error)
}                                                  // origin live
// Requests: exactly these three newline-terminated lines
//   {"method":"initialize","id":1,"params":{"clientInfo":{"name":"quotamon","title":"Quota Monitor","version":"0.1.0"}}}
//   {"method":"initialized"}
//   {"method":"account/rateLimits/read","id":2}
// ParseAppServerOutput scans stdout line by line, ignores unparseable lines and
// anything whose "id" != 2, takes result.rateLimits by EXPLICIT path
// (rateLimitsByLimitId is a decoy). An {"id":2,"error":…} → source.Transport
// with error.message. No id:2 line → source.Malformed.
func ParseAppServerOutput(stdout []byte) (limits any, err error)
// codex not on PATH → source.NotConfigured("Codex CLI not installed — install it or use `codex login`")

// --- local: rollout tail ----------------------------------------------
type LocalSource struct{ Home string; MaxFiles int /*16*/; TailBytes int /*512 KiB*/ } // origin local
// Fetch: Home/sessions missing → NotConfigured("No Codex sessions found at …");
// walk for *.jsonl, newest MaxFiles by mtime; for each, LastLine(containing
// "rate_limits") reading the tail first (drop the partial leading line), whole
// file if the tail has no hit; parse the line; limits = root.payload.rate_limits
// (explicit path); observedAt = root.timestamp else mtime. When every window
// has rolled over, status = NeedsSetup("ChatGPT reports usage only after a
// Codex turn — last reading <age>"). No hit anywhere → NoDataFound.
func LastLine(path string, needle string, tailBytes int) (string, bool, error)

// --- optional HTTP ------------------------------------------------------
type HTTPSource struct{ Home string; Endpoint string; Client *http.Client }   // origin live
// Only constructed when QUOTA_MONITOR_CODEX_USAGE_URL is set (T-0011 wires it).
// Token: Home/auth.json → tokens.access_token, header ChatGPT-Account-Id from
// tokens.account_id when present. Headers: Authorization, Accept,
// User-Agent: quotamon/0.1. NO `originator`, NO spoofed UA (PROVIDERS.md trap 2).
// Response: if it has rate_limit.primary_window (the wham/usage shape), map
// primary_window/secondary_window with used_percent, limit_window_seconds/60 →
// minutes, reset_at; else treat body["rate_limits"] or body as the limits
// object. Never store user_id / email.
```

## Questions

The app-server fixture and its acceptance criterion disagree about the primary
reset timestamp. The fixture's `resetsAt` is `1788038896`; interpreting that as
epoch seconds, as `PROVIDERS.md` requires, produces
`2026-08-29T21:28:16Z`, not the criterion's `2026-08-29T02:08:16Z`.

The options are to correct the acceptance timestamp to `21:28:16Z`, or change
the captured fixture's epoch value to one representing `02:08:16Z`. Changing
the parser to produce the stated wall-clock time from the existing value would
violate the cross-cutting timestamp contract. I recommend correcting the
acceptance timestamp because the fixture is described as a real reply and is
outside this ticket's scope.

## Answers

PM answer: the acceptance criterion had a typo — mine, not the fixture's.
`1788038896` epoch seconds is `2026-08-29T21:28:16Z`, which is what the parser
must produce. Keep the fixture untouched, keep the implementation as is, and
treat the criterion as reading `21:28:16Z`. Your tests already assert the
correct value; hand off to review.
