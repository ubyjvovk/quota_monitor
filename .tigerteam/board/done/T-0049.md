## Goal
`quotamon setup` treats ANY config load error as first-run and silently
overwrites the file with defaults, destroying stored API keys (opus F5,
codex F1: malformed JSON or 0644 perms → key gone with no warning).

## Design — implement exactly this
- Only `config.ErrMissing` proceeds as first-run. Any other load error prints
  the error plus what to do (fix perms / fix JSON), and exits non-zero WITHOUT
  writing. No --force flag — the fix is fixing the file.
- Tests: malformed JSON → non-zero exit, file byte-identical after; 0644
  config carrying an api_key → refused, untouched; missing file → setup
  proceeds as today.

## Acceptance criteria
- [ ] `bash .tigerteam/scripts/run-tests.sh` exits 0
- [ ] The three tests above exist and pass
- [ ] No files changed outside scope

## Out of scope
