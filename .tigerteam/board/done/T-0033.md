## Goal
The macOS app is about to render the **exact** text the `quotamon` console
prints (same columns, same `█░` bars, same colouring) — see T-0034. It needs
that text as data, with colour spans, computed from the `QuotaSnapshot` it
already holds, and re-computed as the clock ticks (countdowns/ages change
while the panel is open). Port `core/cmd/quotamon/table.go` to Swift as a
pure function in QuotaKit, and prove parity with a golden test against the Go
demo output.

## Design — implement exactly this
### `Credits.spend`

### `QuotaKit/Sources/QuotaKit/Support/ConsoleTable.swift`
```swift
/// The `quotamon` console table, as data. A line-for-line port of
/// core/cmd/quotamon/table.go; the golden test pins it to the Go output, so
/// any change to the table layout must land in both files.
public enum ConsoleTable {
    public enum Tone: Sendable, Equatable { case plain, warning, critical }
    public struct Span: Sendable, Equatable {
        public let text: String
        public let tone: Tone
    }
    public struct Line: Sendable, Equatable {
        public let spans: [Span]
        /// The spans concatenated — what the console prints without colour.
        public var text: String { spans.map(\.text).joined() }
    }
    /// One provider block per provider, in the snapshot's own order (the
    /// console never re-ranks), separated by one empty `Line` — exactly like
    /// `renderTable`'s "\n\n" join. Empty input → empty array.
    public static func render(_ providers: [ProviderSnapshot], asOf now: Date) -> [Line]
    /// The block for one provider: header, windows, credits, status line.
    public static func render(_ provider: ProviderSnapshot, asOf now: Date) -> [Line]
    /// `render(_:asOf:)` joined with "\n" — byte-identical to `quotamon`'s
    /// uncoloured table for the same snapshot.
    public static func text(_ providers: [ProviderSnapshot], asOf now: Date) -> String
}
```
- Tone rules = Go's `--color` rules: on a window row with a reading, the
  filled `█` run and the percent text carry the row's severity tone
  (`warning`/`critical`); a `normal` severity is `.plain`. The `░` remainder,
  the padding, the label and the countdown are always `.plain`. Everything on
  a row splits into spans only where the tone changes; a fully plain line is a
  single span. Header, credit and status lines are always one plain span.
- Header: `padTableCell(displayName, 12) + " " + padTableCell(plan ?? "—", 14) + " " + origin + " · " + age` where origin is `live` / `cached` / `unavailable`
  exactly as `tableOrigin` maps `.live` / `.local` / else. (Go prints the age
  for every origin, including unavailable — match Go, not `ConsoleReport`.)
- Window row: `"  " + truncateAndPad(label, 9) + " " + bar + " " + percentPadded + "  " + countdown` where the percent is right-aligned to 4 cells, `—` when
  `currentUsedPercent(asOf:)` is nil; bar = `round(used/5)` clamped 0…20 `█`
  then `░` to 20 cells (all `░` when no reading); countdown = `—` when
  `resetsAt` is nil, `reset` when it is in the past, else `QuotaFormat.countdown`.
- Credits: port `creditLines`/`tableCredits` exactly (balance+spend rows when
  `spend != nil && !unlimited`; `spend`/`credits` label rules; the
  disabled-zero omission with currency symbols and whitespace trimmed and
  `,`→`.` before parsing).
- Status: when `status` is not `.ok`, append `"  !  " + message`.
- Rune counts, not UTF-16 counts, for all padding (`—`, `…`, `█` are one cell each).

### Fixture + tests (`ConsoleTableTests.swift`)
- Generate the fixture once: `cd core && GOTOOLCHAIN=local GOPROXY=off go run ./cmd/quotamon --demo --json > ../QuotaKit/Tests/QuotaKitTests/Fixtures/quotamon-demo.json`. Commit it.
- `demoTableMatchesTheGoGoldenByteForByte`: decode the fixture with
  `QuotaSnapshot.decode(from:)`, call `ConsoleTable.text(snapshot.providers, asOf: snapshot.generatedAt)`, and `#expect` it equals the golden string copied
  verbatim from `demo_test.go` (paste it as a Swift multi-line literal; every
  `█`/`░` count matters).
- `spendDecodesFromTheCoreContract`: DeepInfra in the fixture decodes with
  `credits.spend == "$8.00 this month"` and `balance == "$10.03"`.
- `criticalRowColoursBarAndPercentOnly`: the ChatGPT `5h` line of the demo is
  spans `["  5h        ", plain] ["████████████████████", critical] [" ", plain] ["100%", critical] ["  8m", plain]`
  (adjust spacing to what Go emits — the `text` must still equal the golden
  line). Every other demo line is a single `.plain` span.
- `warningToneAt70Percent`: a window at 70% → the `█` run and `70%` are
  `.warning`; at 69% both `.plain`.
- `resetWindowRendersDashAndEmptyBar`: a window whose `resetsAt` is in the
  past → bar is 20 `░`, percent cell is `   —`, countdown `reset`.
- `statusLineFollowsTheBlock`: a `.needsSetup("run `codex login`")` provider
  ends with `  !  run `codex login``.
- `providersAreSeparatedByOneEmptyLine`: two providers → exactly one
  `Line(spans: [])` (or a single empty plain span — pick one and document it)
  between blocks and none trailing.
