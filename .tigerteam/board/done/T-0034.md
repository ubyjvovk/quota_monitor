## Goal
The product owner compared `docs/console.png` (the terminal) with
`docs/app-light.png` (the Tufte panel) and prefers the terminal. Make the
menu-bar panel look **exactly** like the console screenshot: same monospace
face, same columns and `█░` bars, same colouring, same spacing — in a dark
palette matching the screenshot and a light counterpart that follows the
system appearance. The panel's chrome (header with refresh, Settings/About/
Quit footer, first-run setup pane) stays, restyled in the same face.

## Context
- **The reference rendering:** `docs/console.png`, produced by
  `scripts/screenshot-console.py` — read it, it defines the numbers below:
  font `/System/Library/Fonts/SFNSMono.ttf` at 26px on a 2x canvas (= **SF
  Mono 13pt**), line height `ascent+descent+8px` (= **4pt extra leading**),
  canvas padding 28px (= **14pt**), background `(30,30,36)`, text
  `(222,222,226)`, warning `(222,180,60)`, critical `(232,90,82)`.
- **The lines come from T-0033** (already on `feature/console-look`, your
  worktree starts there): `ConsoleTable.render(_ providers:, asOf:) -> [Line]`,
  `Line.spans: [Span]`, `Span.text`, `Span.tone: .plain|.warning|.critical`.
  Provider blocks are separated by an empty `Line`. Do not re-implement any
  table logic in `App/`; if the lines are wrong, block with `## Questions`.
- Current panel code: `App/QuotaPanelView.swift` (keep its structure:
  header / table-or-setup / footer, `now` timer, first-run detection),
  `App/ProviderSection.swift` + `App/QuotaBar.swift` (DELETE — replaced),
  `App/SetupView.swift` (restyle), `App/DesignSnapshot.swift` (the
  `QUOTA_MONITOR_RENDER` headless PNG path — keep the contract, swap the
  sample), `App/QuotaMonitorApp.swift` + `App/MenuBarIcon.swift` (untouched).
- `Tufte` (QuotaKit/UI) stays for the widget; **`App/` must stop importing
  it entirely** — the panel gets its own theme below.
- The Go demo snapshot the console screenshot shows: `core/cmd/quotamon/demo.go`.

## Design — implement exactly this
### `App/ConsoleTheme.swift` (new)
```swift
enum ConsoleTheme {
    /// SF Mono 13pt — the face scripts/screenshot-console.py draws with.
    static let font = Font(NSFont.monospacedSystemFont(ofSize: 13, weight: .regular))
    static let lineSpacing: CGFloat = 4     // console: ascent+descent+8px @2x
    static let padding: CGFloat = 14        // console: 28px @2x
    static let width: CGFloat = 400         // 46 console columns + padding
    static let background: Color   // light #FFFFF8  dark #1E1E24 (30,30,36)
    static let text: Color         // light #1E1E24  dark #DEDEE2 (222,222,226)
    static let warning: Color      // light #B8860B  dark #DEB43C (222,180,60)
    static let critical: Color     // light #C8433B  dark #E85A52 (232,90,82)
    static var chrome: Color { text.opacity(0.6) }   // header/footer/meta text
    static var rule: Color { text.opacity(0.15) }    // hairlines
}
```
Dynamic colours use the same `NSColor(name:) { appearance in … }` pattern as
`Tufte.dynamic` (copy it — `DesignSnapshot` relies on `NSApp.appearance` to
flip them, and a plain `colorScheme` check would not).

### `App/ConsoleTableView.swift` (new)
- Input: `[ConsoleTable.Line]`. Build ONE `AttributedString`: lines joined by
  `"\n"`, each span coloured by tone (`.plain` → `text`, `.warning` →
  `warning`, `.critical` → `critical`). Render as one `Text` with
  `.font(ConsoleTheme.font)`, `.lineSpacing(ConsoleTheme.lineSpacing)`,
  `.textSelection(.enabled)` (copyable, like a terminal),
  `.fixedSize(horizontal: false, vertical: true)`, leading-aligned,
  `frame(maxWidth: .infinity, alignment: .leading)`. Long status lines wrap;
  nothing truncates.

### `App/QuotaPanelView.swift`
- `.frame(width: ConsoleTheme.width)`, `.background(ConsoleTheme.background)`.
- Table = `ConsoleTableView(lines: ConsoleTable.render(engine.snapshot.providers, asOf: now))`
  — **snapshot order, not `rankedProviders`** (the console does not re-rank),
  padded `ConsoleTheme.padding` on all sides. The 30-second `now` timer keeps
  countdowns/ages live exactly as today.
- Header: `Quota Monitor` (left) + `arrow.clockwise` (right, 12pt symbol) in
  `ConsoleTheme.font` / `.chrome`; keep the refresh behaviour and
  `ProgressView`. Footer: Settings / About / Quit, same font and colour,
  symbols kept. Hairlines: `ConsoleTheme.rule`, 1pt. Horizontal padding 14,
  vertical 8 — as now.
- Empty state (`Reading providers…` / `No readings yet.`) and the
  `warning` line under the footer rule: `ConsoleTheme.font`; `.chrome` for
  the empty state, `.critical` for warnings.
- Delete `App/ProviderSection.swift` and `App/QuotaBar.swift`.

### `App/SetupView.swift`
- Replace every `Tufte.serif/meta(...)` with `ConsoleTheme.font`, `Tufte.text`
  → `ConsoleTheme.text`, `Tufte.textSecondary` → `ConsoleTheme.chrome`,
  `Tufte.highlight` → `ConsoleTheme.critical`. Layout and behaviour unchanged.

### `App/DesignSnapshot.swift`
- Replace `sample` with a Swift transcription of `core/cmd/quotamon/demo.go`
  (`demoSnapshot`): same five providers, ids, display names, plans, window
  ids/labels/kinds/percentages, `resetsAt` offsets from `now`, credits
  (Claude `20.00` disabled; DeepInfra `balance: "$10.03"`, `spend: "$8.00 this
  month"`, unlimited false, enabled true; Kimi/Grok per demo.go), origin live,
  observedAt = now. Result: `docs/app-*.png` will show the same data as
  `docs/console.png`. Keep the render contract (`<prefix>-light.png`,
  `<prefix>-dark.png`, `<prefix>-menubar-*.png`, terminate) untouched.
