## Provider A — OpenRouter (id `openrouter`, DisplayName `OpenRouter`, short name `OR`)
- `GET https://openrouter.ai/api/v1/credits`, `Authorization: Bearer <key>`.
  Response (floats, USD):
  `{"data": {"total_credits": 25.0, "total_usage": 14.37}}`
  → commit as `Fixtures/openrouter-credits.json`.
- Mapping: remaining = max(0, total_credits − total_usage); Balance
  `"$X.XX"`; Spend `"$X.XX all time"` (it is LIFETIME usage — never imply
  monthly); Enabled true; Unlimited false; HasCredits = remaining > 0; no
  windows; Plan nil; ObservedAt now; Origin live.
- Missing/non-numeric `data.total_credits` or `data.total_usage` → Malformed
  (T-0051 rule: never fabricate $0.00).
- Errors: 401/403 → NeedsSetup(`OpenRouter API key rejected — set OPENROUTER_KEY or run: quotamon config set openrouter --api-key-stdin`);
  429 → Transport rate-limited; other non-200 → Transport.
- Env fallback `OPENROUTER_KEY`; discover probe on that env/config key,
  supported + NeedsKey.

## Provider B — DeepSeek (id `deepseek`, DisplayName `DeepSeek`, short name `DS`)
- `GET https://api.deepseek.com/user/balance`, `Authorization: Bearer <key>`.
  Response (money values are STRINGS):
  `{"is_available": true, "balance_infos": [{"currency": "CNY", "total_balance": "110.00", "granted_balance": "10.00", "topped_up_balance": "100.00"}]}`
  → commit as `Fixtures/deepseek-balance.json`.
- Mapping: pick the `balance_infos` entry with currency `USD` when present,
  else the first; Balance formatted per the T-0037 money convention (`$X.XX`
  for USD, `X.XX CNY` otherwise) from `total_balance` (parse the string as a
  decimal; unparsable → Malformed); Spend nil (endpoint reports none);
  Enabled = true; HasCredits = `is_available` && parsed total > 0; Unlimited
  false; no windows; Plan nil.
- Empty/missing `balance_infos` → Malformed. `is_available:false` with a
  zero balance is a normal state, not an error.
- Errors: 401/403 → NeedsSetup(`DeepSeek API key rejected — set DEEPSEEK_KEY or run: quotamon config set deepseek --api-key-stdin`);
  else as OpenRouter.
- Env fallback `DEEPSEEK_KEY`; discover probe likewise.
